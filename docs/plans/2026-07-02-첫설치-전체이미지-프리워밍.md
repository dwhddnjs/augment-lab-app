# 첫 설치 프리워밍 — 전체 이미지 다운 완료 후 메인 진입

## Context (왜 하는가)

앱 최초 실행 시 뜨는 "설치 화면"(`SetupScreen`)은 이미 실제 `Image.prefetch` 기반이지만, **챔피언 아이콘(core)만** 진행률과 함께 받고 완료 즉시 메인으로 넘긴 뒤 나머지는 백그라운드로 받았다. 게다가 프리워밍 대상에서 **아레나 증강·프리즘 아이템·재련(special) 증강이 통째로 빠져 있고**, 칼바람 증강과 ARAM 아이템만 백그라운드 대상이었다.

아레나 기능이 추가되면서 받아야 할 이미지가 크게 늘었고, 메인 진입 후 이미지가 CDN에서 늦게 도착해 **깜빡임(flicker)** 이 심했다. 그래서 첫 설치 때 **아레나+칼바람 증강, 챔피언 사각 아이콘, 전체 아이템 아이콘을 전부 디스크 캐시에 받고, 다운이 100% 완료돼야만 메인으로 진입**하도록 바꿨다. 프로그레스바는 이미 존재하므로 전체 이미지 기준으로 채워지게만 연결했다.

**확정된 범위:**
- 챔피언 스플래시(대형 배경) = **제외** (저장된 빌드에서만 쓰이고 무거움 → 기존 focus prefetch로 커버)
- 아이템 = **전체 254개** 아이콘 포함

## 프리워밍 대상 (전량, 전부 완료 대기)

| 소스 | 훅 | URL 빌더 |
|---|---|---|
| 챔피언 사각 아이콘 | `useChampions()` | `championSquareUrl(c.imageKey)` |
| 역할(클래스) 아이콘 | `CHAMPION_TAGS` | `championClassIconUrl(tag)` (null 필터) |
| 칼바람 증강 | `useAugments()` | `augmentImageUrl(a.iconPath, 'large')` |
| 아레나 증강 | `useArenaAugments()` | `augmentImageUrl(a.iconPath, 'large')` |
| 아레나 재련 증강 | `useSpecialAugments()` | `augmentImageUrl(a.iconPath, 'large')` |
| 아레나 프리즘 아이템 | `usePrismaticItems()` | `cdragonItemIconUrl(p.iconPath)` |
| 전체 아이템 | `useItems()` | `itemImageUrl(it.imageKey)` |

- `AugmentImage`는 항상 `step 0 = 'large'`부터 요청하므로(`src/components/ui/augment-image.tsx:60`) 프리워밍도 `'large'`로 맞춰 첫 렌더 URL과 정확히 일치시켰다.
- 스탯 파편(`useStatShards`)은 아이콘 필드가 없어 제외.
- 최종 리스트는 `Array.from(new Set(...))`로 **중복 제거** 후 사용(겹치는 아이콘 이중 계산 방지).

## 구현 내역

### `src/lib/image-prewarm.ts`
- `runFirstPrewarm` 인자를 `{ coreUrls, restUrls, onCoreProgress }` → `{ urls, onProgress }`로 단순화. core/rest 분리·백그라운드 rest 호출 제거. 전량 `prefetchPool` 완료 후 완료 플래그 기록.
- 개별 prefetch 타임아웃 안전장치 추가(`prefetchOne` + `PREFETCH_TIMEOUT = 15000`): `Promise.race`로 한 장이 hang해도 진행률이 멈추지 않게 함. 실패·타임아웃 모두 `done += 1`로 카운트 → 오프라인이어도 100% 도달해 앱이 잠기지 않음.
- `CONCURRENCY` 10 → 12로 소폭 상향(약 900장+ 체감 시간 단축).
- `hasPrewarmed()` / `doneFlagKey()`(버전 포함)는 그대로.

### `src/hooks/use-image-prewarm.ts`
- 아레나 훅 3개(`useArenaAugments`, `usePrismaticItems`, `useSpecialAugments`)와 `cdragonItemIconUrl` import 추가.
- `coreUrls`/`restUrls` → 단일 `allUrls`(7개 소스, Set 중복 제거)로 통합.
- 아이템 `ARAM_IDS` 필터 및 `aram-item-ids.json` require 제거 → 전체 254개 포함.
- `runFirstPrewarm({ urls, onProgress })` 호출. `showSetup = needsSetup === true && progress < 1` 로직은 그대로 두어, progress가 전체 이미지 기준이 되면서 자동으로 "전부 완료 시에만 진입"이 됨.

### `src/components/navigation/setup-screen.tsx`
- 변경 없음(프로그레스바 % UI 기존 완성).

## 검증

1. `npm run lint` — 통과.
2. 첫 설치 재현: AsyncStorage `prewarm:done:16.11.1` 키 제거 또는 앱 재설치.
3. `npm run ios` — 프로그레스바가 0→100%(전체 이미지 기준)까지 차오르고 100%에서만 fade-out 후 메인 진입 확인.
4. 메인 직후 아레나 증강 / 칼바람 draft / 아이템 그리드로 이동해 아이콘 깜빡임 없음 확인.
5. 두 번째 부팅 시 설치 화면 스킵(플래그) 확인.
6. (엣지) 기내모드 첫 실행 시 타임아웃 후에도 진행률이 끝까지 차 앱이 잠기지 않는지 확인.
