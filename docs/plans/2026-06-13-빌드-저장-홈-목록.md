# 드래프트 결과 재디자인 + 빌드 로컬 저장 + 홈 빌드 목록 + 빌드 상세 화면

## Context

드래프트 결과 화면(`draft-result-screen.tsx`)이 앱의 글라스 디자인 시스템(GlassChip 헤더 등)과 어울리지 않고, 결과가 어디에도 저장되지 않아 일회성으로 사라진다. 요구사항:

1. 결과 화면을 기존 스타일(GlassChip/테마 토큰)에 맞게 재디자인 — 챔피언·증강 카드 전부(최대 6)·아이템 전부가 보기 좋게 표시
2. 하단 "확인하러 가기" CTA → 빌드 저장 후 메인으로 이동
3. 홈 탭을 저장된 빌드 카드 목록으로 전면 교체 (현재 Expo 보일러플레이트)
4. 카드 탭 → `/build/[id]` 상세 화면(portrait)에서 챔피언/증강/아이템/스탯 표시

**사용자 결정사항**: 저장은 **AsyncStorage 로컬 저장** (Supabase `builds.ts` 쿼리는 auth가 없어 사용 불가 — 보존만 하고 미사용), 홈 탭은 **전면 교체**.

> 구현 시작 시 이 플랜을 `docs/plans/2026-06-13-빌드-저장-홈-목록.md`로 복사 저장할 것 (CLAUDE.md 규칙).

## 핵심 설계 결정

- **저장 모듈은 `src/lib/build-storage.ts`** — draft(쓰기)·builds(읽기) 두 feature가 공유하므로 lib로 승격 (CLAUDE.md 경계 규칙 2). React 의존 없는 순수 async 함수.
- **id만 저장** (`championId`, `augmentIds`, `itemIds`) — `useChampions()`/`useAugments()`/`useItems()` 훅이 로케일별 JSON에서 재해석하므로 로케일 전환에 안전.
- **builds feature는 draft 컴포넌트를 import하지 않음** (feature 간 import 금지). `AugmentCell`/`ChampionSummary`류는 builds 컴포넌트 안에 소규모 자체 구현. champions/items/augments의 훅·타입·`ItemStatPanel` import는 기존 관행(draft가 이미 함)대로 허용.
- 결과 화면(draft feature 내부)은 `DraftCardFrame` 그대로 재사용.
- 홈 목록 카드는 글라스 미적용 (CLAUDE.md "고밀도 리스트 셀 글라스 금지") — `ThemedView surface="raised"`.

## 1. `src/lib/build-storage.ts`

```ts
const STORAGE_KEY = 'builds:v1';

export interface SavedBuild {
  id: string;
  championId: string;
  augmentIds: string[]; // 최대 6 (Transmute: Chaos 포함)
  itemIds: string[];    // 0~6 (skip 시 [])
  createdAt: string;    // ISO 8601
}

listBuilds(): Promise<SavedBuild[]>            // createdAt desc
getBuild(id): Promise<SavedBuild | null>
saveBuild(input: Omit<SavedBuild,'id'|'createdAt'>): Promise<SavedBuild>
removeBuild(id): Promise<void>
```

- `JSON.parse` try/catch → 손상/null 시 `[]` 폴백
- id: `${Date.now().toString(36)}-${Math.random().toString(36).slice(2,8)}` (새 의존성·crypto.randomUUID 사용 금지)

## 2. 결과 화면 재디자인 (landscape 유지)

유지: splash 배경 + `LinearGradient`, landscape lock, `DraftCardFrame`.
교체: 텍스트 헤더와 단색 버튼 → draft-screen과 동일한 **GlassChip** 문법.

```
SafeAreaView
├─ 헤더 행 (row, space-between, paddingHorizontal: Spacing.four)
│   ├─ 좌: GlassChip(handleRestart) — "refresh" 아이콘 + "다시 시작"
│   ├─ 중앙: 정적 GlassChip — 챔피언 square 아이콘(28) + 이름(label) + 칭호(caption)
│   └─ 우: 정적 GlassChip — "check-decagram" + "드래프트 완료"
├─ 본문 행 (flex:1, row)
│   ├─ 좌(flex:7): 증강 카드 horizontal ScrollView — picked 전부 + "#n" 캡션
│   │   cardWidth = min(4열 폭 기준, screenH * 0.52 * 9/14)
│   └─ 우(flex:3): 세로 ScrollView — 아이템 44px 타일 그리드(surface.raised + border.subtle + Radius.sm)
│       + ItemStatPanel(champion.stats, itemStatsList). 아이템 없으면 그리드 숨김
└─ 하단 중앙: GlassChip variant="accent" — "확인하러 가기" CTA
```

CTA 로직: `saving` state로 중복 탭 차단 → `saveBuild()` → 실패 시 Alert 후 중단 / 성공 시 `PORTRAIT_UP` lock 후 `router.dismissTo('/')` (기존 `handleHome` 패턴). 기존 "홈으로" 버튼은 CTA로 대체·제거. 회전 가드(`if (!isLandscape) return <ThemedView/>`)를 draft-screen처럼 추가.

## 3. 홈 탭 — 빌드 목록

`build-list-screen.tsx`:
- `useFocusEffect` + `useCallback`(CLAUDE.md 명시 예외)에서 `listBuilds()` 재조회 → 저장/삭제 후 자동 갱신
- `SafeAreaView(top)` → 헤더(`ThemedText type="title"` "내 빌드" + 개수 caption) → `FlatList` (`paddingBottom: BottomTabInset + Spacing.three`)
- 빈 상태: 중앙 아이콘 + "저장된 빌드가 없어요" + accent 버튼 "드래프트 시작" → `/select-champion-modal`
- 카드 long-press → Alert 확인 → `removeBuild` → state 즉시 갱신

`build-card.tsx` (props: `build`, `onPress`, `onLongPress`):
- `ThemedView surface="raised" elevation={1}`, `Radius.xl`, padding `Spacing.three`
- 1행: 챔피언 square 48(accent 1.5px 테두리) + 이름/칭호 + 우측 날짜(`useLocale()` + `toLocaleDateString`)
- 2행: 증강 28px 타일(최대 6) — `surface.sunken` + `AugmentRarityColors[rarity].border` 테두리 + `augmentImageUrl(iconPath,'large')`
- 3행: 아이템 28px 타일(`itemImageUrl`) — 없으면 숨김
- id 미해석 가드: 챔피언 → placeholder, 증강/아이템 → filter 제거 (crash 금지)

## 4. 빌드 상세 (`/build/[id]`, portrait)

`build-detail-screen.tsx`:
- `useLocalSearchParams` → `getBuild(id)`, 3상태(로딩/정상/없음). `useFocusEffect`로 `PORTRAIT_UP` lock 안전망
- 세로 ScrollView:

  - 하단 삭제 버튼(`status.danger.subtle` 배경) → Alert → `removeBuild` → `router.back()`

## 리스크

- AsyncStorage 손상 → storage 모듈에서 `[]` 폴백
- 데이터 갱신으로 id 미해석 → null 가드/filter, crash 금지
- 중복 저장 → `saving` state 차단
- 6증강 케이스 → horizontal scroll이라 안전, 카드 타일은 wrap 허용
- React Compiler — 수동 `useMemo/useCallback` 추가 금지 (`useFocusEffect` 콜백만 예외)
- typedRoutes — `router.push({ pathname: '/build/[id]', params: { id } })` 형태 사용
