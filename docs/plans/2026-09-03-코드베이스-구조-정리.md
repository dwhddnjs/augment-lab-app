불어난 곳**만 손댄다. UI 픽셀은 한 곳도 바꾸지 않는다.

## E. 경계 규칙에 대한 판단 (코드를 바꾸지 않음)

`augments`·`champions`·`items` 는 **데이터 도메인**이고 `aram`·`arena`·`custom`·`builds` 는
**화면 도메인**이다. 후자가 전자를 참조하는 건 자연스럽고, 실제로 전 코드가 그렇게 짜여 있다.
CLAUDE.md 의 "다른 feature 를 import 하지 않는다" 를 문자 그대로 적용하면 타입 60여 개를
`src/` 루트로 끌어올려야 하는데 이득이 없다. 규칙 쪽에 예외를 명시하는 것으로 정리한다.

`hooks/use-image-prewarm.ts` 가 feature 5개를 import 하는 것도 같은 이유로 둔다 —
"부팅 시 모든 도메인 이미지를 받는다"가 그 훅의 정의라 모든 도메인을 알 수밖에 없다.
