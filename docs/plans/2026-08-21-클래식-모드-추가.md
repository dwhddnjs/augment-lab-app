# 클래식(아수라장 클래식 스타일) 모드 추가

## Context

앱은 지금 **칼바람**과 **아레나** 두 모드의 빌드를 만든다. 26.16 패치로 증강이 갱신되면서
**무작위 총력전: 아수라장 — 클래식 스타일**(CDragon `KIWI_JADE`, 맵 453 "Classic Rift")을
세 번째 모드로 붙인다.

플로우·UI는 칼바람과 같다(챔피언 선택 → 가로 드래프트 3장 → 아이템 → 빌드 상세).
**다른 것은 셋뿐이다.**

1. 증강 풀이 클래식 풀이어야 한다
2. 라운드가 4 또는 **5**다 — 진입 시 "바론한테 간식 10개를 주셨나요?"를 묻고 갈린다
3. 아이템이 **완전히 다른 레트로 세트**다

### 조사로 확정된 사실

**증강 — 이미 다 있다. 배선만 하면 된다.**
`augments.{ko,en}.json` 280개에 `modes` 태그가 이미 붙어 있다(커밋 `2092f7d`).

| modes | 개수 |
| --- | --- |
| `["aram","classic"]` | 156 |
| `["classic"]` | 31 |
| `["aram"]` | 55 |
| `[]` (미출시/제거) | 38 |

→ 클래식 풀 **187개**. `useAugmentPool('classic')` 한 줄로 나온다. 데이터 작업 0.

**아이템 — 진짜로 없다. 사용자 지적이 맞았다.**
클래식은 협곡 아이템을 쓰지 않는다. **시즌 초기 레트로 아이템 세트**(`77xxxx` id)를 쓴다 —
스타크의 열정, 쌍둥이 그림자, 아트마의 창, 지휘관의 깃발, 마드레드의 피갈퀴손,
얼음 정수의 파편, 리글의 랜턴, 고대인의 의지 같은 구버전 아이템이다.
앱의 `items.{ko,en}.json` 254개(협곡 map 11)에는 **한 개도 없다.**

정답지는 **게임 bin**이다. 리포가 아레나 증강 수치에 `map30.bin.json`을 쓰는 것과 같은 구조:

```
https://raw.communitydragon.org/latest/game/data/maps/shipping/map453/map453.bin.json
```

`Maps/Shipping/Map453/Modes/JADE` 에서 포인터를 따라간다:

| 포인터 | 내용 | 개수 |
| --- | --- | --- |
| `itemLists[]` → `GameModeItemList.mItems` | 상점 전체(`77xxxx`) | **150** |
| `itemLists[]` → 다른 하나 | 소모품·장신구·와드 | 35 |
| `mItemShopData` → `ItemShopGameModeData.CompletedItems` | **완성 아이템** | **81** |

- 150개 전부 DDragon 16.16.1 `item.json`에 이름·설명·가격·태그가 있다(누락 0).
- 아이콘도 `.../16.16.1/img/item/773031.png` → **HTTP 200** 확인.
- `CompletedItems` 81개는 상점 150개의 부분집합이다(검증 완료). 칼바람의
  `aram-item-ids.json` 111개와 정확히 같은 역할 — 6칸 빌드 그리드에 띄울 목록.

> ⚠️ **버전 올려야 한다.** 앱은 `version.json`에 `16.11.1`로 고정돼 있고
> 그 버전에서는 `773031.png`가 **403**이다. `16.16.1`로 올려야 레트로 아이콘이 뜬다.
> id 기반 URL이라 기존 254개 아이콘은 올려도 그대로 뜬다.

> ⚠️ **해시 키를 하드코딩하지 말 것.** `{7d7e7c08}` 같은 키는 패치마다 바뀔 수 있다.
> 반드시 `Modes/JADE`에서 `itemLists` / `mItemShopData` 포인터를 따라가고,
> 두 itemList 중 **원소가 `77`로 시작하는 쪽**을 상점으로 고른다.

### 1. 데이터 — 클래식 레트로 아이템 수급

**새 스크립트** `scripts/fetch-classic-items.mjs` (기존 `.mjs` 스크립트 관례를 따른다.
`scripts/fetch-data/fetch-ddragon.ts`는 없어진 `src/data/`·`src/types/`를 참조해 **깨져 있으니 쓰지 말 것**):

1. `map453.bin.json` 다운로드 → `node_modules/.cache/augment-data`에 캐시
   (`scripts/apply-mayhem-patch.mjs`의 캐시 패턴 그대로, `--refresh` 플래그 포함)
2. `Modes/JADE` → `itemLists` / `mItemShopData` 포인터를 따라 상점 150 + 완성 81 추출
3. DDragon `16.16.1` `item.json` ko_KR / en_US 에서 150개 메타 조립 —
   `fetch-ddragon.ts:47`의 매핑 형태(`id/name/description/plaintext/gold/tags/stats/imageKey`)를 그대로
4. 출력:
   - `src/features/items/data/classic-items.ko.json` / `.en.json` (150개)
   - `src/features/items/data/classic-item-ids.json` (완성 81개 id 배열)
5. ko/en 개수·id 순서 일치 검증 후 저장 (기존 `check-augment-data.mjs`와 같은 방어)

**`scripts/parse-item-stats.mjs`** — `DATA_DIR`의 `items.*.json` 한 쌍만 처리한다.
파일명 쌍을 배열로 돌게 바꿔 `classic-items.*.json`도 스탯을 채운다.

**`src/lib/version.json`** — `ddragonVersion`을 `16.16.1`로.
부수효과: 프리웜 완료 플래그가 `prewarm:done:16.16.1`로 바뀌어 **기존 사용자도 1회 재프리웜**한다
(의도된 동작, `use-image-prewarm.ts` 설계 그대로).

> 협곡 254개 아이템 자체의 16.16.1 재수집은 **이번 범위 밖**으로 둔다 —
> 칼바람·아레나 전 화면의 스탯이 흔들리는 별개 변경이다. 별도로 처리할 것.

## 검증 (`/verify`)

`.agents/skills/verify/SKILL.md` 절차대로. 타입체크·lint 통과는 검증이 아니다 —
시뮬레이터에서 굴린 것만 기록한다.

**빌드 전 데이터 검증**
```bash
node scripts/fetch-classic-items.mjs && node scripts/parse-item-stats.mjs && npx tsc --noEmit && npm run lint
```
- `classic-item-ids.json` 81개가 `classic-items.ko.json` 150개의 부분집합인지
- ko/en 개수·id 순서 일치

**시뮬레이터 시나리오** (MCP `mcp__Claude_Code_iOS_Simulator__control`)
1. 앱 삭제 후 재설치 → 설치 화면 진행률이 **100%까지 도달**하고 멈추지 않는지 (아이템 +150, 증강 +31)
2. `+` → 버튼 3개(아레나/칼바람/**클래식**)가 + 버튼을 가리지 않는지
3. 클래식 → 챔피언 선택 → 가로 전환 → **간식 다이얼로그**
4. **"아니오" → 라운드 인디케이터 `0 / 4`**, 4픽 후 아이템 화면
5. 되돌아와 **"예" → `0 / 5`**, 5픽 후 아이템 화면 (드로어 6칸)
6. 카드 증강이 **클래식 풀**인지 — 칼바람 전용 55개가 안 나오는지 표본 확인
7. 아이템 그리드가 **레트로 아이템**인지(스타크의 열정·쌍둥이 그림자 등), 아이콘이 검은 박스가 아닌지
8. 6개 선택 → 저장 → 빌드 상세에 증강·아이템이 정상 렌더되는지
9. 홈 → **클래식 필터**에 방금 빌드가 보이고, 칼바람·아레나 필터에는 안 보이는지
10. 스크롤 → **헤더 우측 3세그먼트 토글**이 타이틀과 안 겹치는지
11. 칼바람 1회 완주 — **회귀 없는지**(증강이 칼바람 풀, 아이템이 기존 111개)
12. ko/en 전환 — 클래식 아이템·증강 이름이 양쪽 다 뜨는지

**기록**: `docs/verification/<YYYY-MM-DD>-클래식-모드-추가.md` + `docs/verification/README.md` 인덱스 행.
