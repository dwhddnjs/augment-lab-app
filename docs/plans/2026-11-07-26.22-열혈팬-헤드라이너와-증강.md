# 26.22 열혈 팬 헤드라이너 + 아수라장 증강 반영 (+ PBE 26.23 조사)

## Context

26.22(2026-11-03) 패치로 아수라장에 Worlds 테마 헤드라이너가 들어왔고, 신규 증강 2개와 수치 변경이 있다.
사용자는 "21레벨까지 오르고 21레벨에 증강 하나를 더 주는 월드 챔피언십 헤드라이너"를 게임에서 봤다.
패치 노트에는 이 헤드라이너가 **없다**(노트는 "스타덤을 향한 여정 마지막 페이지"·신규 증강 2개만 적는다).
그래서 게임 데이터로 확인했다.

### 2. 26.22 증강

- **신규 2** (CDragon 16.22 KIWI 풀 + 패치 노트 일치): 원 히트 원더(골드), RISE(프리즘). 원 히트 원더는 위키 표기(스킬 가속 10당 7.5%) 대신 게임 툴팁 표기(100당 75%, 같은 비율)로 썼다.
  설명은 위키 `MayhemAugmentData`(16.22 반영됨) 수치로 썼다. 패치 노트 문구("최대 3회 초기화")와 위키("5초 재사용, 최대 2회, 회당 25%")가
  다른 RISE 는 위키(게임 데이터 추출)를 따른다. 게임 문자열도 "최대 2회 추가로 재사용"이라 위키와 맞는다 — 노트의 3회는 첫 시전까지 센 것으로 본다.
- **풀에서 빠짐 3** (패치 노트엔 없음): 인내심, 눈덩이 업그레이드, 양자 연산. 16.21 → 16.22 `augment-lists.json` KIWI 에서 빠졌고
  위키 데이터에서도 지워졌다. 풀이 정답이라는 원칙대로 `modes: []`.
  (풀에서 빠진 9개 중 나머지 6개는 앱에서 이미 비공개였다.)

## 결정 (기본값으로 정함)

- **표시명**: 게임 내 이름 `열혈 팬 / Superfans`. 패치 노트에 이름이 없어 게임 문자열을 쓴다.
- **드래프트 규칙**: 선택 5회(`roundsFor = 5`). 게임도 K/DA 보너스와 같은 종류의 AugmentModifier 를 쓴다.
- **라운드 표시** (사용자 지시): 열혈 팬은 `라운드 0 / 5` 로 센다. 21레벨 선택이 5라운드다. 처음엔 pill 라벨을 `21레벨` 로 바꿨다가 지웠다. K/DA 는 보너스가 덤이라 `4 / 4` 그대로다.
- **보너스 등급**: 공개 자료가 없어 일반 라운드와 같은 확률(`RARITY_ODDS`). K/DA 보너스와 같다.
- **등장 풀**: 9종 균등.
- **로고** (사용자 지시): 게임 원본 흰 실루엣(`worlds.png`). 처음엔 브랜드 로고처럼 금색 윤곽을 둘렀으나 "왜 노랗냐"는 지적으로 원본으로 되돌렸다. 라이트 모드 판 없는 자리(헤더)에서는 다른 흰 로고처럼 글자색으로 칠한다(`WHITE_LOGOS`).
- **5라운드 카드 마크** (사용자 지시, 인게임 캡처 기준): 흰 로고에 파란 빛을 두른 `worlds-card.png` 를 카드 윗변 가운데에 걸친다. 로고 폭 = 카드 폭의 30%, 그림 상자의 55% 가 윗변 위로 나간다. 빛나는 그림이라 라이트에서도 칠하지 않는다.
- **조명색**: `HeadlinerColors.worlds = #2E5BC9`(Worlds 2026 키 비주얼 블루).
- **설명 줄바꿈**: `hangul-word` 도 숫자와 한글 사이를 끊어("5 / 라운드") ko 설명의 `21로`·`5라운드`·`21레벨` 에 U+2060(WORD JOINER)을 `⁠` 이스케이프로 넣었다.
- **빌드 상세 증강 아이콘** (사용자 지시): 타일 48 → 56pt(그림 36 → 42pt). 홈 카드와 함께 쓰는 `AugmentTile` 비율은 그대로다.
