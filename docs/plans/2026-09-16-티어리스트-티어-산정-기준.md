# 티어리스트 티어 산정 기준 교체 — 소스 tier 채택

## Context

티어리스트 S티어에 말이 안 되는 챔피언이 있고 다른 사이트와 결과가 많이 다르다는 지적에서 시작했다. 대표 사례: **징크스가 다른 사이트에선 S인데 우리 앱엔 없다.**

### 검증 결과 — 데이터는 정확하다

야스오 56.6% / 픽 10.5%를 교차검증했다.

| 소스 | 승률 | 픽률 | 모드 | 지역 |
|---|---|---|---|---|
| 우리 앱 (16.17) | 56.6% | 10.5% | 광란 | CN |
| dtodo 원본 (16.18) | 56.6% | 10.9% | 광란 | `source:"tencent", region:"CN"` |
| ARAMKit (16.18, 15.6M 매치) | 57.5% | 10.6% | 광란 | 글로벌 |
| Blitz / Mobalytics / mayhemmeta | 53.2~53.7% | — | **일반 칼바람** | 글로벌 |

- **지역: 중국(텐센트) 서버.** 국내(KR) 아님. 다만 글로벌 소스와 1%p 이내로 붙어 실질 차이는 없다.
- **모드: 칼바람 광란(아수라장).** 일반 칼바람 소스는 전부 53%대 → 우리 수치는 광란 기준이 맞다. 지금 화면 출처 문구에 이 구분이 없다.
- 정합성 확인: 픽률 합계 정확히 10.000(게임당 10명), 픽률 가중 평균 승률 49.99%. 온전한 집계다.

### 진짜 원인 — 소스가 주는 tier를 버리고 있었다

`champions.json`의 `stats.tier`(1~5)를 우리만 안 쓰고 승률로 재정렬하는 중이었다. 다른 사이트는 전부 이 값을 쓴다.

```
tier 1 (7명):  야스오 TF 헤카림 아우솔 티모 케이틀린 탐켄치
tier 2 (19명): 릴리아 요네 모르가나 케일 케인 에코 세라핀 마스터이 신짜오 유나라
               라이즈 그레이브즈 베인 세트 징크스 신지드 브랜드 미포 스몰더
tier 3 이하:   그웬(3) 흐웨이(3) 암베사(3) 피오라(3) 벨베스(4)
```

- arammayhem.com의 "S티어 19명" = **tier 2 그룹과 완전 일치**
- aramgg.com은 징크스를 S로 표기(51.66% / 10.98% — 우리와 같은 숫자)
- 저픽 고승률(그웬 3.5%, 벨베스 3.2%)은 소스가 이미 tier 3~4로 내린다

이 tier는 승률+픽률 선형결합으로 역산되지 않는다(최적 k에서도 tier1 적중 4/7). 표본 수 등 노출되지 않는 정보가 들어가 있어, 자체 공식을 만들면 영원히 다른 사이트와 어긋난다. 픽률 보정(m=0.04)으로도 징크스는 승률 51.7%라 S에 못 든다.

**결론: 공식을 만들지 말고 소스 tier를 쓴다.**

### 매핑 (확정)

`tier 1+2 → S(26)` / `3 → A(26)` / `4 → B(18)` / `5(103명)`는 승률순으로 갈라 `C(52) / D(51)`.

## 변경

### 1. `scripts/fetch-data/fetch-tierlist.ts` — 티어를 빌드타임에 굽는다

`Row`에 `tier: 'S'|'A'|'B'|'C'|'D'` 추가. 챔피언 루프에서 `cs.tier`(숫자)를 임시 필드로 들고 있다가, 정렬 직후 문자로 변환하고 임시 필드는 버린다.

```ts
// 기존: aram.sort((a, b) => b.score - a.score);
aram.sort((a, b) => a.srcTier - b.srcTier || b.score - a.score);

// 소스 tier(1~5) → 표시 티어. tier5가 103명(60%)이라 승률 기준 반으로 갈라 C/D로 나눈다.
const MAP: Record<number, Tier> = { 1: 'S', 2: 'S', 3: 'A', 4: 'B' };
const half = Math.ceil(aram.filter((r) => r.srcTier === 5).length / 2);
let i5 = 0;
for (const row of aram) {
  row.tier = MAP[row.srcTier] ?? (i5++ < half ? 'C' : 'D');
  delete (row as any).srcTier;
}
```

- 루프 진입 가드에 tier 누락 방어 추가: `if (!cs || cs.winRate == null || cs.tier == null) continue;`
- 기존 sanity 가드(150명 미만이면 중단)는 그대로 — tier가 통째로 빠지면 여기서 걸린다.

### 2. `src/features/tierlist/tiers.ts` — 백분위 컷을 들어낸다

- `TierRow`에 `tier: Tier` 추가
- **`CUTS` 상수 삭제** (주석 포함)
- `tierOf(key)` → `findTierRow(key)?.tier ?? null` 한 줄
- `tierSections()` → `rows.filter((r) => r.tier === title)` 후 기존 격자 묶기 그대로. `prev`/`slice`/`Math.round` 전부 제거
- `tierRankOf(key)` → 배열이 더 이상 승률순이 아니므로 **승률 기준으로 센다**:
  ```ts
  const row = rows.find((r) => r.key === key);
  return { rank: row ? rows.filter((r) => r.score > row.score).length + 1 : 0, total: rows.length };
  ```
- 파일 상단 주석의 "승률 내림차순으로 이미 정렬" → "소스 티어 순(동티어 내 승률순)으로 정렬"로 수정

### 3. `src/features/tierlist/screens/tierlist-screen.tsx` — 출처 문구

ko/en `source` 를 수정. 추가할 사실 두 가지:
- 챔피언 통계가 **칼바람 광란(아수라장)** 기준이라는 것
- 티어는 aram.gg 자체 티어(승률+픽률 종합)이고 우리가 다시 계산하지 않는다는 것

기존의 "중국(텐센트) 서버", "증강은 클라이언트 업로드 표본", "아이템은 일반 칼바람" 문구는 전부 검증으로 사실 확인됨 — 유지.

### 4. `src/features/tierlist/screens/tierlist-champion-screen.tsx` — 순위 라벨

`rank: '{total}명 중 {rank}위'` → 승률 기준임을 명시(`'승률 {total}명 중 {rank}위'` / `'#{rank} of {total} by win rate'`). 티어 배지와 순위가 어긋나 보이는 걸 막는다.
