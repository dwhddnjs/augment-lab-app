# 커스텀 모드 — 아이템 선택 통합

## Context

커스텀 모드(`/custom`)는 증강만 직접 고르는 샌드박스로 들어왔다. 빌드는 증강 + 아이템으로 완성되는데, 지금은 아이템을 담을 방법도, 결과를 저장할 방법도 없다(`custom-screen.tsx:213` 의 ponytail 주석이 "다음 턴에 완료 버튼"이라 남겨둔 자리).

화면을 하나 더 만들지 않고 **같은 화면에서 헤더 토글로 증강↔아이템을 오간다**. 가로 6.5:4.5 레이아웃은 그대로 두고, 좌측 리스트만 갈아끼우고 우측 선택 영역을 5:5로 쪼갠다. 마지막으로 체크 버튼이 `saveBuild`로 빌드를 만들어 상세로 보낸다 — `draft.mode`가 그대로 저장 모드라 칼바람 빌드는 칼바람 목록에, 클래식은 클래식 목록에 쌓인다.

확정 사항: 아이템 최대 6개(기존 `MAX_ITEMS`와 동일), 드롭 판정은 **우측 패널 전체**(하이라이트만 드래그 중인 종류의 박스에 켬).

---

## 1. 상태 — `src/features/custom/hooks/use-custom-draft.ts`

기존 증강 상태 옆에 아이템 상태를 나란히 붙인다. 새 훅을 만들지 않는다.

```ts
export type PickTarget = "augment" | "item";
export type AddResult = "added" | "duplicate" | "full";   // "full" 추가

const [target, setTargetState] = useState<PickTarget>("augment");
const [itemFilter, setItemFilter] = useState<FilterKey>(null);
const [items, setItems] = useState<Item[]>([]);
const [saving, setSaving] = useState(false);
```

- `itemPool = useItemPool(mode)` (`@/features/items/hooks/use-items`) — 모드 전환 시 아이템 풀도 함께 바뀐다.
- `itemList` = `itemPool` → `FILTERS.find(f => f.key === itemFilter)?.predicate` → `matchName(it.name, query)` (증강 리스트와 같은 파이프라인, `@/lib/hangul` 재사용).
- `setTarget(next)`는 `setQuery("")`를 함께 호출한다 — 증강 검색어가 아이템 목록을 비우는 혼란 방지.
- `addItem(item): AddResult` — 중복이면 `"duplicate"`, `items.length >= MAX_ITEMS`(6)면 `"full"`, 아니면 추가. `add`와 같이 `setItems(prev => ...)`로 stale 방지.
- `removeItem(id)` / `clear()`는 증강·아이템을 **모두** 비운다(휴지통 라벨이 "선택 초기화"라 전체가 자연스럽다).
- `save()` — `useItemSelect.handleSave`(`use-item-select.ts:136`)와 같은 절차:
  `saveBuild({ mode, championId, augmentIds, itemIds })` → `await lockOrientation(PORTRAIT_UP)` → `router.dismissTo("/")` → `router.push("/build/[id]")`. 실패 시 `Alert`. `saving` 가드로 연타 차단.
  (`useItemSelect` 쪽 로직은 클로저에 묶여 있어 추출하면 두 파일이 바뀐다 — 20줄 중복을 택하고 아이템 선택 화면은 건드리지 않는다.)

## 2. 드래그 공용화 — `src/features/custom/components/drag-cell.tsx` (신규)

`augment-pick-grid.tsx`의 `AugmentDragCell` 안 Pan 제스처 블록을 그대로 옮겨 제네릭 래퍼로 만든다(롱프레스 180ms · `blocksExternalGesture` · `onTouchesCancelled` 취소 경로 포함 — 이 세 가지가 빠지면 드래그 중 리스트가 흐르거나 고스트가 남는다).

```ts
type DragPayload =
  | { kind: "augment"; augment: Augment }
  | { kind: "item"; item: Item };

<DragCell payload={...} enabled={!quickMode} listGesture={...} ghostX ghostY
          onDragStart onDragEnd>{children}</DragCell>
```

`augment-pick-grid.tsx`는 이 래퍼를 쓰도록 바꾸고 카드 렌더만 남긴다.

## 3. 좌측 아이템 그리드 — `src/features/custom/components/item-pick-grid.tsx` (신규)

`AugmentPickGrid`와 같은 구조: 세로 필터 레일 + `FlatList numColumns={8}`.

- 필터 레일은 `ItemFilterBar`(`@/features/items/components/item-filter-bar`, `SIDE_TAB_WIDTH=44`)를 **그대로 import**. 요구사항이 "기존 아이템 필터 탭 디자인"이고, 딸려오는 `FILTERS`·`FilterIcon`이 전부 items 도메인이라 `components/ui`로 승격할 수 없다. `build-detail-screen.tsx:33`이 이미 `ItemStatPanel`을 같은 방식으로 쓴다.
- 셀 크기는 그리드 실측 폭 onLayout → `(w - gap*7)/8` (기존 `ItemGrid`와 같은 계산, 하한 36).
- 셀 = `DragCell` + `RemoteImage(itemImageUrl(item.imageKey))`, 담긴 아이템은 `ItemGrid`와 같은 accent 테두리 + 체크 배지.
- 퀵모드면 탭으로 담긴다(증강과 동일 — 드로어 설정은 전역 조작 방식).

## 4. 헤더 토글 — `src/features/custom/components/pick-target-toggle.tsx` (신규)

`AugmentSearchField` 오른쪽. 트랙 전체가 하나의 `Pressable`이라 누를 때마다 반전한다.

- `GlassSurface` pill 트랙 + 2칸(각 32pt), 안에 `withTiming` 으로 좌우 이동하는 **원형 노브**(`colors.accent.subtle`, `Radius.full`).
- 아이콘: 증강 `shimmer`, 아이템 `sword` (MaterialCommunityIcons). 활성 쪽만 `accent.default`, 반대는 `text.tertiary`.
- 노브 색·이동은 `mode-switch.tsx`의 `HeaderModeToggle`(`features/builds/components`) 패턴을 따른다 — 움직이는 pill 은 글래스가 아니라 단색(매 프레임 굴절 재계산으로 끊긴다).
- 전환 시 `Haptics.selectionAsync()`.

## 5. 헤더 재배치 — `custom-screen.tsx`

`✕ | 검색 | 토글 | ✓ | 설정` 순. `✓`는 `GlassButton systemImage="checkmark" tint={colors.accent.default}` → `draft.save()`.
`AugmentSearchField`는 placeholder 만 분기하면 되므로 `target` prop 하나를 받는다(파일명은 유지, 사전에 `placeholderItem` 키 추가).

좌측 본문은 `draft.target === "augment" ? <AugmentPickGrid/> : <ItemPickGrid/>`.

드래그 상태는 `dragged: DragPayload | null` 하나로 통일하고, 고스트는 payload 종류로 분기(`AugmentTile` vs `RemoteImage`). 드롭 판정(`absoluteX > dropBoundary`)과 `overDrop` 계산은 지금 그대로 두고, `commit`만 payload 종류로 `draft.add` / `draft.addItem` 을 고른다. `"full"` 결과는 warning 햅틱.

## 6. 우측 선택 패널 5:5 — `selected-panel.tsx`

챔피언 행은 그대로 두고 그 아래 박스를 두 컬럼으로 쪼갠다(`flexDirection: "row"`, 각 `flex: 1`, `gap: Spacing.two`).

- 각 박스 위에 `caption` 라벨: `증강 3` / `아이템 2/6` — 빈 상태에서 어느 칸이 무엇인지 읽히게.
- 하이라이트는 `dropTarget: PickTarget | null` prop 으로 받아 **드래그 중인 종류의 박스에만** accent 테두리 + `accent.subtle` 배경(`dropActive` 를 대체).
- 아이템 행은 증강 행과 같은 레이아웃(아이콘 30 + 이름, 탭하면 제거). 왼쪽 3pt 바 색은 증강이 rarity 색, 아이템은 `colors.border.strong`.
- 챔피언 행 아이콘 버튼이 3개가 된다: `chart-bar`(신규 · 스탯) / `account-switch-outline` / `trash-can-outline`. 기존 `iconButton` 헬퍼 재사용.

## 7. 스탯 모달 — `src/features/custom/components/champion-stat-overlay.tsx` (신규)

`ChampionChangeOverlay`와 같은 뼈대(backdrop `surface.overlay` + 배경 탭 닫기 + `GlassSurface` 시트, 세로 inset 먹지 않음).

내용: 챔피언 아이콘(52) + 이름 + `title` + tags → 그 아래 `ItemStatPanel`(`@/features/items/components/item-stat-panel`)에 `baseStats={champion.stats}` / `itemStatsList={draft.items.map(i => i.stats)}`. 스탯 항목이 가로 화면 높이를 넘으므로 `ScrollView`로 감싼다. 아이템으로 붙은 증가분은 패널이 이미 `(+n)` accent 로 그린다.

## 건드리지 않는 것

- `/aram-items`(ItemSelectScreen)·`useItemSelect` — 커스텀은 그 화면을 거치지 않는다. `custom-screen.tsx:213` 의 낡은 ponytail 주석은 삭제.
- 증강 개수 제한 없음(현행 유지). 모드 전환 시 담긴 항목을 거르지 않는 현행 정책도 유지 — 아이템은 `useItemPool`이 모드별로 갈리므로, 모드를 바꾸면 담긴 아이템이 그 모드 풀에 없을 수 있다. 저장은 id만 하고 상세는 `useItems()`(전체 목록)로 되살리므로 깨지지는 않는다. `use-custom-draft.ts:73` 주석에 아이템 몫을 한 줄 덧붙인다.

## i18n

새 키는 각 파일 상단 `t = { ko, en }` 에: `placeholderItem`(아이템 이름 검색) · `augments`/`items` 라벨 · `emptyItemDrag`/`emptyItemTap` · `stats`(스탯 버튼 · 모달 제목) · `saveError`.

## 검증 (`.agents/skills/verify`)

1. `npm run lint` + `npx tsc --noEmit`.
2. `/prebuild` 로 iOS 시뮬레이터 실행 → `+` → 커스텀 → 챔피언 선택.
3. 손으로 굴릴 항목:
   - 토글 탭 → 노브가 움직이고 좌측이 필터 레일 + 아이템 그리드로 바뀐다. placeholder 도 바뀐다.
   - 아이템 검색("무한", 초성 "ㅁㅎ") → 걸러진다. 증강으로 되돌리면 검색어가 비고 증강 그리드가 온전하다.
   - 아이템 카드 롱프레스 드래그 → **아이템 박스만** 하이라이트 → 우측 어디에 놓아도 담긴다. 7개째는 warning 햅틱만 울리고 안 담긴다.
   - 증강 드래그 중에는 증강 박스만 하이라이트된다.
   - 드로어 퀵모드 ON → 아이템도 탭으로 담긴다.
   - 스탯 버튼 → 모달에 챔피언 정보 + 스탯, 아이템 담긴 항목에 `(+n)`이 붙는다.
   - 드로어에서 모드를 클래식으로 → 아이템 그리드가 레트로 세트로 바뀐다.
   - ✓ → 세로로 회전하며 빌드 상세가 뜨고, 증강·아이템·합산 스탯이 모두 보인다. 홈 목록에서 칼바람/클래식 세그먼트에 맞게 쌓였는지 확인.
4. 결과를 `docs/verification/<오늘>-커스텀-아이템-선택.md` 에 기록(스크린샷 커밋 금지). 이 플랜 문서도 `docs/plans/<오늘>-커스텀-아이템-선택.md` 로 복사.
