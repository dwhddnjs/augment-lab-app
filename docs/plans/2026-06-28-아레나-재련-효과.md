# 아레나 재련(8라운드) 증강 효과 구현

## Context

8라운드 재련(`reforge`) 단계는 현재 카드를 골라도 `pickReforge`가 `reforgeIds`에 id만
쌓고 넘어갈 뿐 **실제 효과가 없다**(`use-arena.ts`). drawer에도 재련 결과가 표시되지
않는다. 사용자가 재련 3종에 실제 게임 효과를 요청했다.

확정 사항(사용자):
- 재련 풀은 **3종만 노출**(`REFORGE_IDS`를 3종으로 축소):
  `crafting-pris-stat-anvil`(프리즘 능력치 모루 획득),
  `crafting-augment-slot`(증강 슬롯 획득), `crafting-sell-augment`(증강 강화).
  → `gain-stat-anvil`·`replace-augment` 제외.
- 재련 결과는 drawer에 **새 '재련' 섹션**으로 표시.

각 효과:
1. **프리즘 능력치 모루 획득** — 선택 시 drawer '재련' 섹션에 기록(아이콘+이름).
2. **증강 슬롯 획득** — 선택 시 플래그 set → **12라운드 진입 시 랜덤 실버 증강 1개 자동 부여** + drawer 기록.
3. **증강 강화** — 선택 시 **보유 증강 3장 선택 오버레이**. 카드당 1회 리롤(아직 안 보여준
   보유 증강으로 교체). 선택 → 그 증강 제거 + 남은 증강 중 레벨업 여지 있는 것들에
   **총 2레벨 랜덤 분배**(각 최대 레벨 한도 내).

## 변경 파일

1. `src/features/arena/hooks/use-arena.ts` — `REFORGE_IDS` 3종 축소, `augmentSlotGranted`
   state, `advance`의 12라운드 보너스 실버 부여, `pickReforge` 슬롯 플래그, 신규 `enhanceAugment`.
2. `src/features/arena/components/arena-enhance-picker.tsx` (신규) — 보유 증강 3장 선택 오버레이.
3. `src/features/arena/screens/arena-screen.tsx` — 재련 카드 onPick 분기, enhance picker state/렌더,
   drawer에 reforgeIds 전달.
4. `src/features/arena/components/arena-drawer.tsx` — '재련' 섹션 추가, reforgeIds prop, dict.
