# 증강 드래프트 → 아이템 선택 페이즈 추가

## Context

칼바람나락 증강 드래프트 앱은 현재 `증강 4픽 완료 → 결과 화면(draft-result)`으로 바로 넘어간다.
그 사이에 **아이템 선택 페이즈**를 새로 끼워 넣는다. 사용자가 챔피언에 맞는 아이템 6개를
고르면서 스탯이 실시간 합산되는 것을 보고, 최종 빌드를 결과 화면에서 확인하게 한다.
이 화면은 옵셔널이라 skip 가능하다. 동시에 앱을 리퀴드글라스 스타일로 전환하기 시작한다
(이번엔 좌측 정보 패널/툴팁/오버레이에만 적용, 아이템 카드 자체는 제외).

## 플로우

```
draft (4픽 완료)
  └─ router.replace('/draft-items', { picked, championId })
draft-items (ItemSelectScreen, landscape 유지)
  ├─ skip 또는 6칸 채움
  └─ router.replace('/draft-result', { picked, championId, items })
draft-result (선택 아이템 + 합산 스탯 추가 표시)
```

## 새로 생성된 파일

- `src/app/draft-items.tsx` — 라우트 재export
- `src/features/items/components/item-select-screen.tsx` — 메인 아이템 선택 화면
- `src/features/items/components/item-stat-panel.tsx` — 합산 스탯 글래스 패널
- `src/features/items/components/item-slot-grid.tsx` — 3×2 아이템 슬롯
- `src/features/items/components/item-tooltip.tsx` — LoL 스타일 툴팁
- `src/features/items/stats.ts` — 스탯 합산 순수 함수
- `src/features/items/item-text.ts` — description HTML 파서
- `src/components/ui/glass-surface.tsx` — 범용 리퀴드글라스 프리미티브

## 수정된 파일

- `src/features/draft/components/draft-screen.tsx` — done 시 `/draft-items`로 변경
- `src/features/draft/components/draft-result-screen.tsx` — items param 수신, 아이템/스탯 표시
- `src/app/_layout.tsx` — draft-items 라우트 등록
- `CLAUDE.md` — 리퀴드글라스 원칙 추가

## 아이템 필터 기준

`gold.purchasable === true && (gold.total >= 2000 || tags.includes('Boots'))`

## 리퀴드글라스

- `expo-glass-effect` (이미 설치) + `expo-blur` (폴백, 신규 설치)
- `GlassSurface` 컴포넌트로 통일. 직접 GlassView/BlurView 호출 금지
- 아이템 그리드 셀에는 미적용 (성능)
