# 아레나 증강 슬롯·오버레이·재련 개선 (2026-06-30)

## 배경
arena 화면에서 4가지 수정 요청.

## 변경 사항

### 1. 모루(전설/프리즘) 카드 오버레이가 헤더까지 전체를 덮도록
- `arena-anvil-picker.tsx`: 오버레이를 `Modal`(transparent, fade,
  supportedOrientations 가로)로 감쌌다. 기존엔 상점 컨테이너 내부 absolute라
  헤더가 가려지지 않았다.

### 2. 매 증강턴에 보유한 레벨업 가능 증강 1장 보장
- `use-arena.ts`에 `buildAugmentCards()` 추가. 슬롯에 여유가 있으면 신규 증강
  위주이되 레벨업 가능한 보유 증강이 있으면 랜덤 1장을 반드시 끼운다.

### 3. 증강 슬롯 한도(기본 4, 재련 시 5) + 아이템 6개 한도
- `BASE_AUGMENT_SLOTS=4`, `REFORGED_AUGMENT_SLOTS=5`(augmentSlotGranted 시).
- 슬롯이 꽉 차면 `buildAugmentCards`가 보유 증강(레벨업 가능)만 노출 → 레벨업 유도.
- `rerollAugment`도 슬롯 풀 상태에선 보유 증강으로만 교체.
- `MAX_ITEMS=6`: `buyItem` 가드 + 상점 셀/전설 모루 셀 cap 비활성화(dim).

### 4. 빌드 상세 재련 표시 + 재련 아이콘 선명화
- `crafting_*` 아이콘은 흐릿한 단색 라인아트라 sunken 배경에서 흐리게 보임.
  `AugmentImage`에 `imageTint` prop 추가 → 골드(`#E8B339`) 솔리드 틴트로 선명화.
  drawer·build-summary 양쪽 적용.
- `SavedBuild.reforgeIds` 추가 + arena-screen `saveBuild`에서 저장 +
  `ArenaBuildSummary`에 재련 섹션 렌더.
