# 아레나 화면 4종 개선 플랜

## Context

아레나(`src/app/arena.tsx` → `src/features/arena/`) 게임 화면에서 사용자가 4가지 UX 문제를 지적했다.

1. **헤더 라운드/골드 배치** — 현재 라운드와 골드가 한 줄(row)에 붙어 나와 좁고 읽기 어렵다. 라운드 아래에 골드가 오도록 세로(column)로 바꾼다.
2. **R1 골드 지급 타이밍** — 지금은 R1 증강 카드를 고른 뒤(boots step 진입 시) 500골드를 준다. 1라운드가 시작되면(증강 선택 화면에서) 곧바로 500골드가 보여야 한다.
3. **상점 UI 단조로움** — R1 신발 상점이 신발 그리드만 보여줘 일반 상점(R4·6·9·11, 좌측 카테고리 탭)과 따로 논다. 모든 라운드가 **하나의 통합 상점 UI**(전체 카테고리 노출)를 재사용하고, 골드 부족 항목은 비활성 처리한다.
4. **카드 선택 애니메이션 부재** — R1 증강 카드를 누르면 바운스 없이 즉시 신발 리스트로 전환된다. 칼바람 드래프트(`DraftCard`)와 **동일한 카드 선택 애니메이션**(선택 카드 scale 바운스 + 나머지 fade-out → 다음 단계)으로 통일한다.

목표: 칼바람 드래프트와 결을 맞춘 매�끄러운 아레나 진행 흐름.

## 작업 1 — 헤더 라운드/골드 세로 배치

**파일**: `src/features/arena/screens/arena-screen.tsx`

`styles.roundBox`를 `flexDirection: "row"` → `"column"`으로. 라운드 텍스트(`{round}/{totalRounds}`)가 위, `goldRow`가 아래로 쌓이게 한다.
- `roundBox`: `alignItems: "center"`, `gap`을 `Spacing.two` → `Spacing.half` 수준으로 축소(세로 간격 정리), 좌우 패딩 유지.
- 헤더 중앙 `GlassSurface`가 두 줄이 되어 살짝 높아지므로 `header`의 `alignItems: "center"`로 좌우 GlassButton과 수직 정렬 유지(현재도 center라 추가 작업 없음).

## 작업 2 — R1 시작 시 500골드 즉시 지급

**파일**: `src/features/arena/hooks/use-arena.ts`

- 초기 골드: `useState(0)` → `useState(500)` (R1 증강 화면부터 500 보유).
- `ARENA_STEPS`의 R1 상점 step에서 `gold: 500` 제거(작업 3에서 `kind`도 `shop`으로 통합) → 카드 선택 후 추가 지급 없음.

골드 총량은 변하지 않고, **지급 시점만** 카드 선택 전으로 당겨진다.

## 작업 3 — 통합 상점 UI(전체 카테고리 노출, 신발 카테고리 추가)

R1 전용 `boots` 모드를 없애고, 모든 상점 라운드가 카테고리 탭이 있는 동일 UI를 쓴다. 신발을 살 수 있도록 **신발 카테고리**를 탭에 추가한다.

**`src/features/arena/types.ts`**
- `ArenaStepKind`에서 `'boots'` 제거 → R1 상점도 `'shop'`. 주석(R1 = 증강 + 신발 상점) 갱신.

**`src/features/arena/hooks/use-arena.ts`**
- `ARENA_STEPS` R1: `{ round: 1, kind: 'boots', gold: 500 }` → `{ round: 1, kind: 'shop' }`.

**`src/features/arena/components/arena-shop.tsx`**
- `mode` prop 제거(항상 통합 카테고리 UI 렌더). `Props`·`mode === "boots"` 분기 삭제.
- `CATS` 배열 맨 앞에 신발 카테고리 추가: `{ key: "boots", label: "boots", icon: "shoe-formal"(또는 적절한 MCI), price: SHOP_PRICE.boots }`. `ShopCat` 타입에 `"boots"` 추가.
- 신발 카테고리 선택 시(`cat === "boots"`) 기존 `bootsPool` 그리드(`ItemCell` price=500)를 `content` 영역에 렌더.
- 기본 선택 카테고리(`useState<ShopCat>`)는 `"boots"`로(R1에서 바로 신발이 보이도록). 전체 카테고리는 골드와 무관하게 항상 노출되고, `ItemCell`의 기존 `affordable`(gold≥price) 로직이 자동으로 부족 항목을 비활성(회색)한다 — 추가 작업 불필요.

**`src/features/arena/screens/arena-screen.tsx`**
- `const isShop = arena.step.kind === "shop" || arena.step.kind === "boots"` → `=== "shop"`.
- `<ArenaShop mode={... "boots" : "shop"} .../>`에서 `mode` prop 제거.

## 작업 4 — 카드 선택 애니메이션을 칼바람과 통일

칼바람 `DraftCard`(`src/features/draft/components/draft-card.tsx`) + `DraftScreen.handlePick`(`src/features/draft/screens/draft-screen.tsx:108`) 패턴을 그대로 이식한다.

### 패턴 요약(칼바람)
- 카드별 `exitMode`(`none`/`picked`/`unchosen`/`reroll`)·`entryMode`(`flip`/`fade`)를 props로 받아 `useSharedValue`(opacity/scale/rotateY)로 애니메이션.
- `picked`: scale `1.05→1` 바운스. `unchosen`: fade-out + scale-down. 새 라운드 진입은 `flip`.
- `handlePick`: `animating=true` → 선택 카드 `picked`/나머지 `unchosen` 세팅 → **380ms 후** 실제 state commit(`pick`)·다음 카드 flip·`roundKey++`.

### 적용 — 공용 애니메이션 래퍼 도입
세 종류 선택 카드(증강/프리즘/재련)가 같은 동작을 공유하도록, `DraftCard`의 Animated 로직을 아레나용 공용 래퍼로 추출한다.

**신규 `src/features/arena/components/arena-pick-card.tsx`**
- props: `index`, `exitMode`, `entryMode`, `disabled`, `onPress`, `children`.
- `DraftCard`의 `useSharedValue`/`useEffect`/`useAnimatedStyle` 블록을 그대로 옮겨, `children`(카드 프레임)을 감싸는 `Animated.View` + `Pressable`만 담당. 레벨 별표·리롤 버튼 등 카드별 부가 UI는 children/형제로 둔다.

**`arena-augment-card.tsx` / `arena-prismatic-card.tsx` / `arena-reforge-card.tsx`**
- 기존 `FadeIn`(augment) 등을 `ArenaPickCard` 래퍼로 교체. `exitMode`/`entryMode`/`index`를 props로 받아 전달.
- 증강 카드의 `LevelStars` 오버레이·리롤 버튼은 현행 유지(래퍼 children 안/밖 배치).

**`arena-screen.tsx` — 애니메이션 상태 관리**
- `exitModes`/`entryModes`(길이 3 배열), `animating`, `roundKey` state 추가(칼바람과 동일).
- `handlePickAugment(idx, aug)`: `animating` 가드 → 선택 idx만 `picked`, 나머지 `unchosen` → `setTimeout(380)` 후 `arena.pickAugment(aug)` 호출 + `exitModes` 리셋·`entryModes` flip·`roundKey++`·`animating=false`.
- 프리즘/재련도 동일한 `handlePick*` 래핑(통일성). 카드 `key`에 `roundKey` 포함해 step 전환 시 재마운트(flip 등장).
- step 전환(예: augment→shop)은 380ms 애니메이션 종료 후 `advance`가 일어나므로, 선택 카드 바운스가 보인 뒤 상점이 등장한다 → 요청 4 충족.

> 주의: 아레나 카드 `key`는 현재 `${stepIndex}-${id}`. flip 재등장을 위해 `${roundKey}-${stepIndex}-${id}` 형태로 변경.

## 검증

1. `npm run ios`로 시뮬레이터 실행 → 챔피언 선택 후 아레나 진입.
2. **작업1**: 헤더 중앙에 라운드(위)/골드(아래) 세로 정렬 확인.
3. **작업2**: R1 증강 선택 화면에서 골드가 이미 `500` 표시되는지 확인.
4. **작업4**: 증강 카드 탭 → 선택 카드 scale 바운스 + 나머지 fade-out 후 상점 등장(칼바람과 동일 감각) 확인. 프리즘(R2)·재련(R8)도 동일 동작.
5. **작업3**: R1 상점에 좌측 카테고리 탭(신발/전설/모루…)이 모두 보이고, 신발 탭에서 500골드 신발 구매 가능·전설(2500)은 비활성(회색) 확인. R4 상점도 동일 UI.
6. `npm run lint` 통과.
7. 플랜 문서를 `docs/plans/2026-06-26-아레나-화면-개선.md`로 복사 저장(CLAUDE.md 규칙).
