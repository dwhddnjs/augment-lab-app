# 아레나 시즌2 증강 레벨·프리즘 아이템 데이터 정확도 개선

## 배경

아레나(시즌2) 증강·프리즘 아이템 정보가 부정확하다는 문제 제기. 조사로 세 가지 근본 원인을 확인했다.

1. **증강 레벨이 전부 잘못 표시됨** — 아레나 시즌2 핵심 신규 기능이 "증강 레벨업"인데, 실제로는 증강마다 레벨업 가능 여부와 최대 레벨이 다르다(CDragon `dataValues.MaxLevel`). 앱은 이를 무시하고 `MAX_AUGMENT_LEVEL = {silver:2, gold:2, prismatic:3}`을 rarity 기준으로 일괄 적용해 모든 증강에 별이 붙었다. 실제 분포는 **MaxLevel 1(레벨업 불가) 54개 / 2 → 100개 / 3 → 47개**이며 rarity와 독립적(실버에 maxLevel 3, 프리즘에 maxLevel 1 존재).
2. **프리즘 아이템 설명 부실** — CDragon `items.json` 원문 HTML을 그대로 사용해 일부 수치가 `"0의 마법 피해"`처럼 비어 있었다(보정용 dataValues 없음). 12개 아이템이 해당.
3. **검수 HTML** — 이미 칼바람/아레나로 분리돼 있었으나 통합 진입점이 없고 maxLevel·프리즘 효과가 노출되지 않았다.

## 구현 결과

### 1. 데이터 파이프라인 — maxLevel 추출
- `scripts/fetch-data/fetch-arena.ts`: `extractMaxLevel(dataValues)` 추가, `ArenaAugment`에 `maxLevel` 필드. `npx tsx scripts/fetch-data/fetch-arena.ts`로 시즌2 최신 + maxLevel 포함 재생성(증강 201개).

### 2. 타입
- `src/features/arena/types.ts`: `ArenaAugment`를 `Augment` 별칭 → `extends Augment { maxLevel: number }` 확장 인터페이스로 전환. `MAX_AUGMENT_LEVEL` 상수 **삭제**(maxLevel 단일 출처).

### 3. 앱 로직 — maxLevel 단일 출처
- `hooks/use-arena.ts`(5곳), `screens/arena-screen.tsx`(nextLevel + 카드 prop), `components/arena-enhance-picker.tsx`: `MAX_AUGMENT_LEVEL[rarity]` → `augment.maxLevel`.
- 별 표시 가드(`maxLevel > 1`): `arena-augment-card.tsx`, `arena-drawer.tsx`, `arena-build-summary.tsx`. MaxLevel=1 증강은 별 미표시 + 픽 즉시 maxed 처리되어 레벨업 후보/재등장에서 제외.

### 4. 프리즘 아이템 위키 보강
- `src/features/arena/data/prismatic-overrides.{ko,en}.json` 신규: 0값 12개 아이템의 고유 효과·수치를 LoL Wiki 기준 평문으로 보강(id→description).
- `fetch-arena.ts`의 `fetchPrismaticItems`가 오버라이드를 머지 → 재fetch해도 보강 유지.
- `src/features/items/item-text.ts`: `prismaticEffectSummary()` 추가. `arena-build-summary.tsx` 프리즘 섹션을 아이콘 → 아이콘+이름+효과 요약으로 개선.

### 5. 검수 HTML
- `scripts/gen-arena-check.mjs`: 증강에 maxLevel 별 배지(`★ 최대 N레벨` / `레벨업 불가`), 헤더에 레벨업 가능/불가 분포, 프리즘 description 평문화.
- `scripts/gen-check-index.mjs` 신규 → `docs/index.html`: 칼바람/아레나 검수 통합 진입 인덱스.
- 재생성: `node scripts/gen-arena-check.mjs && node scripts/gen-augment-check.mjs && node scripts/gen-check-index.mjs`.

## 검증
- `grep '"maxLevel"' augments.ko.json` → 1:54 / 2:100 / 3:47 ✓
- 프리즘 0값 12개 보강 확인, raw HTML 태그 잔존 0 ✓
- `npx tsc --noEmit` → 아레나/item-text 관련 에러 0(themed-text 6개는 선재 에러로 무관), `MAX_AUGMENT_LEVEL` 잔존 0 ✓
- ESLint 통과 ✓
- 검수 HTML 3종 재생성, 인라인 데이터에 maxLevel·평문 description 반영 ✓
