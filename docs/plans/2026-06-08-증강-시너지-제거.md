# 증강 시너지(Augment Synergy) 기능 전체 제거

## Context

다음 패치에서 게임의 **증강 시너지(Augment Set)** 시스템이 삭제될 예정이다. 현재 앱은 시너지 데이터와 이를 표시하는 UI(빌드 드로어의 시너지 카드, 드래프트 카드의 시너지 뱃지)를 가지고 있는데, 곧 무의미해지므로 데이터·로직·UI를 전부 걷어낸다.

**주의 — `SynergyIcon`은 제거 대상이 아니다.** 이름은 "Synergy"지만 실제로는 `MaterialCommunityIcons`를 감싸는 범용 글리프 컴포넌트로, reroll 버튼·드래프트 화면·결과 화면·증강 아이콘 폴백 등 시너지와 무관한 여러 곳에서 일반 아이콘으로 쓰인다. 이 컴포넌트(`src/features/draft/components/synergy-icon.tsx`)는 **그대로 유지**한다.

## 제거 대상 — 파일 전체 삭제

- `src/features/augments/hooks/use-synergies.ts` — `useSynergies`, `getAugmentSynergies`, `SynergyStatus`
- `src/features/augments/data/synergies.json` — 시너지 세트 데이터

## 수정 대상

### 1. `src/features/augments/types.ts`
- `SynergyTier` 인터페이스 삭제 (12–17행)
- `Synergy` 인터페이스 삭제 (19–32행)
- `Augment` 타입은 그대로 유지

### 2. `src/features/draft/components/picked-drawer.tsx`
- import 제거: `useSynergies`(7행), `useLocale`(11행), `SynergyIcon`(16행)
- i18n 사전 `t`에서 `synergy` 키 제거 (ko 22행 / en 38행)
- `const { locale } = useLocale();` 제거 (206행) — 시너지에서만 사용됨
- `synergies` / `activeSynergies` 변수 제거 (214–215행)
- 시너지 카드 렌더링 블록 전체 제거 (`{activeSynergies.length > 0 && (...)}`, 258–326행)
- 관련 스타일 제거: `synergyList`, `synergyCard`, `synergyHeader`, `synergyName`, `tierRow`, `tierBadge`, `tierText` (416–448행)

### 3. `src/features/draft/components/draft-card-frame.tsx`
- import 제거: `getAugmentSynergies`(5행), `SynergyIcon`(10행), `useTheme`(7행)
- `const { colors } = useTheme();` 제거 (84행) — 시너지 뱃지에서만 사용됨
- `const synergies = getAugmentSynergies(augment.id);` 제거 (85행)
- 카드 이름 옆 시너지 뱃지 렌더링 블록 제거 (147–156행의 `<View>{synergies.map(...)}</View>`)
- 미사용 스타일 제거: `synergyBadges`, `synergyBadge` (195–210행)

## 변경하지 않는 것

- `synergy-icon.tsx` (범용 아이콘 — 유지)
- `draft-screen.tsx`, `draft-result-screen.tsx`, `reroll-button.tsx`, `augment-icon.tsx` — `SynergyIcon`을 일반 아이콘으로만 사용하므로 변경 없음

## 검증

1. `npm run lint` — 미사용 import/변수 없는지 확인
2. `npx tsc --noEmit`(혹은 에디터 타입체크) — `Synergy`/`SynergyTier`/`useSynergies` 참조가 모두 사라졌는지 확인
3. `grep -rni "synerg" src --include="*.ts" --include="*.tsx" | grep -vi "synergy-icon\|SynergyIcon"` 로 잔존 시너지 참조가 없는지 확인 (남는 건 범용 아이콘 컴포넌트 참조뿐이어야 함)
4. 앱 실행 후 드래프트 → 증강 선택 → 빌드 드로어 열기: 드로어에 시너지 카드가 없고, 드래프트 카드에 시너지 뱃지가 없으며, 정상 렌더링되는지 확인
