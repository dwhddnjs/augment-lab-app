# 헤드라이너·증강 카드 코드 리뷰 반영 (12건)

- **날짜**: 2026-11-03
- **환경**: iPhone 17 Pro (iOS 26.5), 개발 빌드 + 이 워크트리 Metro. 한국어·영어, 다크·라이트 모두
- **Verdict**: PASS (높이 375pt 기기 — SE·mini — 는 미확인)

## 바꾼 것

| # | 지적 | 수정 |
|---|---|---|
| 1 | 영어 요네 문구가 카드 칸을 넓혀 얼굴·리롤이 카드에서 어긋남 | `StickerLabel` 에 `cardWidth` 를 받아 폭을 `카드 + CARD_GAP` 으로 고정(음수 마진 유지). 칸 폭 기여가 정확히 카드 폭 |
| 2 | 스테이징 상태가 섞여 부분 커밋 시 번들 깨짐 | 새 파일까지 `git add -A` 로 전부 스테이징 |
| 3 | 이름 두 줄이면 설명 마지막 줄이 "…" 없이 잘림 | 이름 `onTextLayout` 으로 줄 수를 재서 설명 줄 수를 1줄 줄인다 |
| 4 | 티어 A(샴페인)와 C(브론즈)가 구분 안 됨 | `TierColors.A` 를 이전 금색(다크 `#E8B339`, 라이트 `#AD821F`)으로 분리 |
| 5 | 영어 카드 밑 묶음 38pt 가 예산(34pt) 초과 | 영어만 줄 간격 12·위 여백 2 → 2 + 24 + 8 = 34pt. 한국어 25pt 그대로 |
| 6 | 라이트 모드 증강 이름이 등급색이라 대비 4.5:1 미달 | 아이템 화면·픽 현황 이름은 라이트에서 `text.secondary`, 다크는 등급색 유지 |
| 7 | 색 표기 정규식 3곳이 서로 다르게 동작 | `features/headliners/marked.ts`(`parseMarked`·`stripMarks`) 하나로 통일. 검사 스크립트가 중첩·짝 오류·없는 색 키·`skillTitle`/`skillBonus` 까지 본다 |
| 8 | 설명 속 골드 금액 강조가 샴페인색이라 안 읽힘 | `AugmentCardColors.amount`(`#E8B339`)로 분리 |
| 9 | 체크 베일(반경 15)·글로우(12)가 그림 모서리와 어긋남 | 그림 모서리 비율 `CARD_CORNER = 0.063`(313px 원본에서 약 20px)을 증강·스킬 카드 글로우와 커스텀 체크 베일이 함께 쓴다 |
| 10 | 라이트 모드에서 멤버 얼굴 테두리가 배경에 묻힘 | `useRarityColors()` 로 라이트 짝 테두리 |
| 11 | HEARTSTEEL 설명이 "일정 확률로"·플랜 문서가 옛 40% 규칙 | 설명을 "매 라운드 증강 2개"로, 플랜 문서에 변경 이력 추가 |
| 12 | 글로우 색·알파 리터럴이 컴포넌트에 있음 | `theme.ts` `AugmentCardColors`(shadow·glowAlpha·kdaGlow)로 이동. 크기 상수(글자 10pt·얼굴 34pt)는 다른 카드처럼 컴포넌트 상수로 둔다 |

## Steps

| 대상 | 드라이브 | 결과 |
|---|---|---|
| 한국어 HEARTSTEEL | `augmentlab://aram?championId=Ahri&headliner=heartsteel` | 이즈리얼·아펠리오스 한 줄, 카드·리롤 위치 이전과 같음. 프리즘 글로우 모서리가 그림 모서리와 맞음 |
| 영어 HEARTSTEEL | 마이페이지에서 English → 드래프트 재시작 반복 | 요네 `Yone: 40% Attack Speed and 20 Ability Haste` 두 줄. 카드 3장 간격 균일, 요네 얼굴이 카드 우상단 모서리에 붙음, 리롤 버튼이 카드 가운데. 한 줄 문구 카드와 리롤 줄 같음 |
| 이름 두 줄 카드 | 영어 라운드 진행(`Ultimate Unstoppable`, `Upgrade Zhonya's`, `Upgrade Death's Dance`) | 설명이 한 줄 줄고 마지막 줄 끝이 "…" 로 끝남 |
| 골드 금액 | `Upgrade Death's Dance` | `250 g…` 가 진한 금색으로 회색 설명과 구분됨 |
| 라이트 모드 드래프트 | 테마 Light → HEARTSTEEL | 실버·프리즘 카드의 멤버 얼굴 테두리가 밝은 배경 위에서 보임. 문구 색 정상 |
| 라이트 픽 현황 | 2장 고른 뒤 Drawer | 증강 칸 이름 회색 보조색, 칸 테두리만 등급색. HEARTSTEEL 설명 새 문구, 케인 요약 `5% Omnivamp` 평문(대괄호 없음) |
| 라이트 티어리스트 | 티어리스트 탭 | A 배너 금색, C 배너 브론즈로 구분됨 |
| 커스텀 체크 베일 | 커스텀 화면에서 ADAPt 드래그로 담기 | 베일이 카드 네 모서리까지 덮고 귀퉁이가 밝게 남지 않음 |
| 규칙 검사 | `npx tsx scripts/check-headliners.ts` | 통과(중첩·짝 오류 파서 단언 포함) |

검증 뒤 시뮬레이터를 한국어·다크로 되돌렸다.

## Findings

- 높이 375pt 기기(12/13 mini, 가로 하단 safe area 21pt)는 HEARTSTEEL 라운드에서 리롤 버튼이 홈 인디케이터 영역에 몇 pt 걸칠 수 있다(계산: 한국어 3pt, 영어 12pt — 이전 툴팁 34pt 와 같은 수준). 이번 변경으로 늘어나지는 않았고, 기기에서 보지는 않았다.
- 영어로 바꾼 뒤 칼바람 종료 확인창은 세로 좌표로 뜬다(ax 좌표를 변환 없이 탭). 앱 문제는 아니고 검증 조작 메모.
