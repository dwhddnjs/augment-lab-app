# 검증 기록 (Verification Log)

시뮬레이터에서 **실제로 앱을 띄워 손으로 굴려본** 결과를 남기는 폴더다.
타입체크·lint 통과는 여기 적지 않는다 — 그건 CI가 한다. 여기 적는 건 **런타임 관찰**뿐이다.

## 언제 기록하나

런타임 동작이 바뀌는 변경(화면·라우팅·플랫폼 분기·네이티브 모듈 교체)을 머지하기 전.
문서·타입·테스트만 건드린 변경은 기록할 게 없다.

## 어떻게 검증하나

`.agents/skills/verify/SKILL.md` 에 빌드·실행·터치 주입·좌표 매핑 레시피가 있다.
Claude Code에서는 `/verify` 로 실행한다(`.claude/commands/verify.md` 가 저 문서를 가리킨다).

## 파일 규칙

- 문서: `<YYYY-MM-DD>-<주제>.md`
- **스크린샷은 저장소에 커밋하지 않는다.** 바이너리는 히스토리에 영구히 남고 검증할 때마다
  누적된다. 관찰한 내용은 문서에 글로 적고, 이미지를 보여줘야 하면 Artifact 페이지로 띄워
  링크를 전달한다(리뷰가 끝나면 사라져도 되는 휘발성 증거로 취급).

각 문서는 **Verdict**(PASS/FAIL/BLOCKED/SKIP), 드라이브한 **Steps**, 그리고
**Findings**(버그만이 아니라 마찰·의외였던 점 포함)를 담는다.
