- 날짜: 2026-08-25
- 대상: 아레나 feature 리팩터링(`arena-rules` 분리, 카드 애니메이션 훅, 오버레이/셀/탭/리롤 버튼 추출, 공용 배열 유틸·가로 잠금 훅)

- 번들: Metro `--clear` 재기동 후 풀 번들 **2056 modules**(리팩터링 전 2048 + 신규 파일 8개). 델타 번들이 아닌 클린 번들에서 재확인했다.

가렌(전사)으로 R1~R12를 끝까지 진행했다.

## 아레나 밖(같이 손댄 코드)

`sampleDistinct` 공용화·`useLandscapeLock`·`cardWidthFor`·`resolveIds`가 닿는 경로.

- **칼바람**: 갈리오 4라운드 완주. 카드 크기·간격 동일, 리롤 정상(같은 등급 유지), 라운드 인디케이터 0/4.
- **아이템 선택**: 8열 그리드, 필터 탭, 트레이 6칸, 선택 2개 시 합산 스탯 델타 갱신, 저장 → 빌드 상세 직행.
- **빌드 상세(칼바람)**: 아이템 행 스탯 요약 + 효과 설명(`<stats>` 중복 없음), 합산 스탯 델타.
- **클래식**: 진입 시 바론 간식 알럿 → '예' → **5라운드로 가로 전환 성공**. 알럿 직후 회전이 걸리는 예민한 경로라 특히 확인했다. 종료 알럿 문구도 "클래식을 종료할까요?"로 모드에 맞게 나옴.

## 남은 것

- 검증 중 만든 빌드 2개(아레나 가렌 / 칼바람 갈리오)가 **시뮬레이터** 저장소에 남아 있다. 필요 없으면 홈에서 길게 눌러 삭제.
- 능력치 모루(`shardIds`) 상점 UI는 여전히 없다. `buyShard`(호출되지 않던 액션)는 지웠고, 저장 포맷과 드로어·상세의 표시 경로는 그대로 뒀다 — 상점이 붙으면 state로 되돌리기만 하면 된다.
