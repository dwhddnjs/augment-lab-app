# 빌드 상세 아이템 섹션 — 인셋 그룹 리스트 전환 + 아이템 개명

- 날짜: 2026-08-25
- 기기: iPhone 17 Pro 시뮬레이터 (라이트 모드, ko)
- 변경:
  - `BuildItemRow`를 아이콘+이름 그리드(IconNameCell)에서 iOS 인셋 그룹 리스트로
    교체. 라운드 컨테이너 1장 안에 6행, 사이는 텍스트 시작점부터 시작하는
    구분선. 아이콘 40 + 이름 + 스탯 요약. 구분선은 `border.subtle`이 다크에서
    `surface.raised`와 명도가 거의 같아 묻히길래 `surface.base`(카드보다 어두운
    배경색) 1px로 바꿨다.
    (중간에 증강과 같은 `DetailCardRow`로 갔다가, 증강 섹션과 너무 비슷해 되돌림.)
  - `formatItemStats()`를 `features/items/stats.ts`에 추가 (STAT_LABELS 재사용).
  - 각 행에 고유 효과 설명 추가. `cleanItemDescription()`
    (`features/items/text.ts`)이 `<stats>` 블록만 걷어내고 나머지는 증강과 같은
    `cleanAugmentDescription`으로 태그를 정리한다.
  - 아이템 `773050` 이름을 "스타크의 열정"/"Stark's Fervor" →
    "지크의 전령"/"Zeke's Herald"로 수정.

## 관찰

- 갈리오 칼바람 빌드 상세 진입. 증강은 좌측 희귀도 라인이 있는 개별 카드,
  아이템은 통짜 흰 컨테이너 한 장 — 두 섹션의 인상이 확실히 갈린다.
  바로 아래 "합산 스탯" 패널과는 자연스럽게 이어진다.
- 이름 줄바꿈 사라짐 — "지휘관의 깃발", "저항 공성기" 모두 한 줄.
- 스탯 요약 확인: 무한의 대검 "공격력 70 · 치명타 확률 25%", 저항 공성기
  "체력 350 · 주문력 50 · 체력 재생 15 · 마나 재생 15"(4개도 한 줄), 영혼의
  갑옷 "체력 520".
- 효과 설명 확인(다크 모드): "무한의 정확성: 치명타 발동 시 200%가 아닌 250%의
  피해를 입힙니다.", 지휘관의 깃발은 오라 + "사용 시 180초" 액티브까지 두 문단으로
  나온다. `<stats>` 블록이 제거돼 위 스탯 줄과 중복되지 않는다.
- 계층: 스탯 줄은 accent(tint) + 600, 효과 설명은 secondary 회색. 아래 "합산 스탯"
  패널의 아이템 증가분(+70)도 accent라 "아이템이 주는 수치 = 민트"로 읽힌다.
  (설명을 tertiary로 뒀던 안은 라이트 모드 #878D96이 흰 배경 3.5:1이라 폐기.
  라이트 accent #18A368도 3.24:1이라 12px 기준 WCAG AA에는 못 미친다 — 굵기와
  짧은 문구로 보완.)
- 구분선 확인(다크): 카드보다 어두운 홈이 파여 6행 경계가 또렷하다.
- 개명 반영 확인 — 목록에 "지크의 전령"으로 표시.
