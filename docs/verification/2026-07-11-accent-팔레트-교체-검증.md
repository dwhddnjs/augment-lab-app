# accent 팔레트 교체 + 탭·스위치·Picker 테마 반영 — 시뮬레이터 검증

- **날짜**: 2026-07-11
- **Verdict**: ✅ **PASS**
- **환경**:
  - iPhone 17 Pro (**iOS 26.5**) — NativeTabs / SwiftUI Picker 경로
  - iPhone 16 Pro (**iOS 18.5**) — `CustomTabBar` 폴백 경로 (같은 debug `.app`을 `simctl install`)

현재 브랜치의 미커밋 변경 중 **런타임 UI가 바뀌는 4건**을 다크·라이트 두 모드에서 굴려 확인했다.
`app.json`의 `android.package` 추가와 `design-system/SKILL.md` 문구는 iOS 런타임과 무관해 대상에서 제외했다
(앱이 정상 부팅함은 홈 로드로 확인).

## 검증 대상

| 파일 | 변경 | 렌더 경로 |
| --- | --- | --- |
| `constants/theme.ts` | accent 팔레트 교체 (다크 `#1ED7A0`→`#00E994`, 라이트 `#0A8466`→`#18A368`, 라이트 `onAccent` 흰색→`#04231A`) | 전역 |
| `navigation/custom-tabs.tsx` | 중앙 `+` 버튼 아이콘 `30`→`34`px, 색 `onAccent`→`inverse` | **iOS 26 미만 폴백 전용** |
| `builds/…/build-list-screen.tsx` | 스위치 트랙 border `subtle`→`default`, 활성 썸 배경 `glass.fill`→`accent.subtle` | 홈 |
| `mypage/…/mypage-screen.tsx` | `<Host key={mode} colorScheme={mode}>` — 테마 변경 시 SwiftUI Picker tint 강제 갱신 | 마이페이지 |

## Findings

### theme.ts — accent 팔레트 (PASS, 양 모드)
- 다크 `#00E994`(밝은 형광 민트) / 라이트 `#18A368`(진한 민트)가 세그먼트·탭·Picker 전반에 일관되게 반영됐다.
- Picker 텍스트 색을 확대 대조하니 다크(밝은 민트)와 라이트(진한 민트)가 **명확히 다른 톤**이었다.
  라이트의 진한 민트는 흰 배경 위 가독이 좋았다(주석의 3.24:1 UI 대비 목표에 부합).

### custom-tabs.tsx — 중앙 `+` 버튼 (PASS, 양 모드)
- ⚠️ 이 컴포넌트는 **iOS 26 미만에서만 렌더**된다(파일 상단 주석대로 iOS 26+는 NativeTabs). 그래서
  iOS 26.5에서는 이 변경이 화면에 **나타나지 않는다** — 검증하려면 iOS 26 미만이 필요하다.
  이번엔 이미 부팅돼 있던 iOS 18.5 시뮬레이터에 같은 debug `.app`을 `simctl install`해 확인했다
  (deployment target 16.4라 설치 가능).
- `onAccent`→`inverse` 변경의 실질 효과는 **라이트모드**에 있다. 다크는 `onAccent`(`#04231A`)나
  `inverse`(`#0E0F12`)나 둘 다 어두워 아이콘이 계속 검정이지만, 라이트는 어두운 `#04231A`에서
  **흰색 `#FAFBFC`로 바뀌어** 진한 민트 배경 위 대비가 개선됐다. 두 모드 모두 아이콘이 잘 보인다.
- 아이콘 34px는 원(56px) 안에서 볼드하게 채워졌다. 30 대비 육안으로 커졌다.

### build-list-screen.tsx — 홈 스위치 (PASS, 양 모드)
- 활성 썸 배경이 중성 글래스(`glass.fill`)에서 **`accent.subtle` 민트 틴트**로 바뀐 것을 다크·라이트 모두 확인.
- 트랙 `border.default`(이전 `subtle`) 외곽선이 렌더됨. 흰 배경 라이트에서도 테두리가 보인다.

### mypage-screen.tsx — `key={mode}` remount (PASS, 핵심)
- **이번 검증의 핵심.** 다크→라이트→다크로 테마를 양방향 토글할 때 SwiftUI Picker의 tint가
  **즉시·정확히** 새 모드의 accent로 갱신됐고, 이전 모드 accent 잔상은 없었다(주석이 우려한 증상).
- 확대 대조: 다크 Picker `#00E994`(밝은 민트) ↔ 라이트 Picker `#18A368`(진한 민트)로 뚜렷이 구분.

## 검증 절차 메모

- **iOS 26 미만 폴백(`custom-tabs.tsx`, `glass-button-fallback.tsx`)을 검증할 땐 iOS 26+ 시뮬레이터로는
  안 된다.** verify skill이 iOS 26+를 권하는 건 glass/NativeTabs 경로 때문인데, 이 폴백들은 정반대 경로다.
  같은 debug `.app`이 여러 iOS 버전(≥16.4) 시뮬레이터에 그대로 설치되므로, 재빌드 없이
  `simctl install <udid> <.app>` + `openurl exp+augment-lab://…?url=http://localhost:8081`로 붙이면 된다.
- 두 시뮬레이터가 동시에 떠 있으면 `cliclick` 좌표가 모호하다(`first window`가 어느 것인지). 한쪽을
  `simctl shutdown`해 창을 하나로 만든 뒤 오프셋을 재는 게 확실했다.
- SwiftUI Picker의 tint 같은 색 변화는 축소본으로는 톤 차이를 놓치기 쉬워, 해당 영역을 원본에서
  crop해 나란히 비교했다.
