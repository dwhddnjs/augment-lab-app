# 열혈 팬 헤드라이너 + 26.22 증강

- **날짜**: 2026-11-07
- **환경**: iPhone 17 Pro (iOS 26.5, 402pt), 개발 빌드(`expo prebuild` → `xcodebuild`), 앱 테마 라이트·다크
- **Verdict**: PASS (아래 미확인 항목 제외)

진입은 개발 빌드 전용 고정 파라미터: `augmentlab://aram?championId=Ahri&mode=aram&headliner=worlds`. 조작은 `orca emulator`.

## Steps

| 대상 | 드라이브 | 결과 |
|---|---|---|
| 등장 연출 | 열혈 팬 진입 | 파란 무대 조명(#2E5BC9) + 흰 Worlds 로고 + `열혈 팬` + 설명. 약 2.6초 뒤 카드 |
| 헤더 | 라이트·다크 | pill 왼쪽에 판 없는 Worlds 로고. 라이트는 글자색, 다크는 흰색. pill 정중앙 유지 |
| 라운드 표시 | 4라운드 진행 | `라운드 0 / 5` → 4픽 뒤 `라운드 4 / 5`(다섯 번째 점 회색). 라벨은 `라운드` 그대로 |
| 5라운드 카드 | 라이트·다크 | 카드 3장 윗변 가운데에 파란 빛 Worlds 로고가 걸침. 헤더 pill 과 겹치지 않음. 라이트에서도 빛 윤곽으로 읽힘 |
| 저장 | 5번째 선택 → 아이템 → 저장 | 아이템 패널·빌드 상세에 `헤드라이너 · 열혈 팬`, `증강 5` |
| Drawer | 픽 현황 | 헤드라이너 행(로고·이름·설명) |
| 설명 줄바꿈 | 등장 화면·상세 | 처음엔 등장 화면에서 `5 / 라운드에서` 로 끊김 → U+2060 넣은 뒤 `마지막 / 5라운드에서 21레벨…` 로 단어 단위 |
| 빌드 상세 증강 아이콘 | 다크 | 타일 56pt, 레이아웃 깨짐 없음 |
| 26.22 수치 | 드래프트 카드 | 전부 다 무너뜨려 `17%`, 트럼펫 폭발 `재사용 50초` 표시 |
| 회귀: K/DA | 4라운드 진행 | `4 / 4` 유지, 카드 위 K/DA 마크 그대로(공용 로고 컴포넌트로 바꾼 뒤에도 같은 크기) |

## Findings

- 시스템 알림(나가기 확인)의 `ax` 좌표는 가로 화면 위에 떠도 **세로 기준**이다. 가로 변환 `(1-y, x)` 를 쓰면 빗나간다. 가로 화면 앱 요소만 변환한다.
- 앱 테마는 앱 설정(마이페이지)이 시스템보다 우선이라 `simctl ui appearance` 로는 바뀌지 않는다.
- 같은 라우트(/aram)에 있을 때 딥링크를 다시 열면 새 판이 시작되지 않는다. 나가기 → 종료 뒤에 연다.
- DetailCardRow 설명은 `hangul-word` 를 쓰지 않아 `얻습니 / 다` 처럼 글자 단위로 끊긴다(Drawer). 기존 헤드라이너 모두 같다 — 이번 범위 밖.

## 미확인

- iPhone 16e 등 낮은 가로 높이 기기에서 5라운드 로고와 헤더 간격
- 영어 로케일 화면
