# 아레나 모드 제거

- 날짜: 2026-09-19
- 기기: iPhone 17 Pro (iOS 26.5, 402×874 pt)
- 빌드: 기존 설치본 + 이 워크트리 Metro(JS만 변경, 네이티브 재빌드 없음). 라우트 파일이
  빠졌으므로 `terminate` + `launch` 로 재시작해 확인했다.
- **Verdict: PASS**

## 무엇을 바꿨나

아레나 모드를 통째로 걷어냈다(`features/arena/`, `/arena` 라우트, `fetch-arena.ts`,
검수 페이지의 아레나·특수 증강·프리즘 데이터셋, 챔피언 선택의 '용기' 타일).
판단 근거는 `docs/plans/2026-09-19-아레나-제거.md`.

기존 로컬 아레나 빌드는 `build-storage` 의 `readAll()` 이 로드할 때 걸러 버린다.
백업 복원도 `reloadBuilds → readAll` 을 거치므로 필터는 이 한 곳에만 있다.

## Steps

### 홈 · 모드 진입점

1. 앱 재시작 → 홈 세그먼트가 **칼바람 / 클래식 2칸**. large title "내 빌드"와 겹치지 않는다.
2. `+` → 오버레이에 **커스텀 / 클래식 / 칼바람 3개**만 뜬다(아래에서 위로 칼바람·클래식·커스텀 순).

### 저장된 아레나 빌드 필터(실데이터)

3. 앱을 끄고 `RCTAsyncLocalStorage_V1` 을 스크래치패드에 통째로 백업했다.
4. `builds:v1` 맨 앞에 가장 최신 날짜의 아레나 빌드 1개를 심었다(징크스, 2026-09-19,
   `prismaticIds` 포함). 그러면 디스크에는 32개가 있다.
5. 앱 실행 → 목록 맨 위가 여전히 **2026.9.18 갱플랭크**. 아레나 빌드는 뜨지 않았고 크래시도 없었다.
6. 아래 드래프트 2판을 저장한 뒤 디스크를 다시 읽었다. **33개(칼바람 21 · 클래식 12),
   `verify-arena` 는 없음**. 다음 쓰기 때 디스크에서도 빠지는 것을 확인했다.
7. 검증을 마친 뒤 앱을 끄고 3번 백업으로 되돌렸다(31개, 테스트 빌드 2개는 제거).

### 칼바람 드래프트 → 저장 → 상세

8. `+` → 칼바람 → 챔피언 선택. **첫 칸이 '용기' 물음표가 아니라 가렌**이다.
9. 가렌 → 시작 → 가로 드래프트 "라운드 0 / 4". 카드 4장을 고르자 아이템 선택으로 넘어갔다.
10. 아이템 2개(가시 갑옷 · 지배자의 피갑옷) → 저장 → 빌드 상세. **칼바람 배지, 증강 4,
    아이템 2, 합산 체력 1390 (+700)**(= 기본 690 + 150 + 550).

### 클래식 드래프트 → 저장 → 상세

11. `+` → 클래식 → 갈리오 → 시작 → "바론한테 간식 10개를 주셨나요?" → **예** → "0 / 5".
    카드 5장 → 아이템 1개 → 저장 → 상세 **클래식 배지, 증강 5**.
    `parseDraftMode` 를 `parseGameMode` 로 합친 경로가 클래식을 칼바람으로 흡수하지 않는다.

### 커스텀 · 삭제된 라우트

12. `+` → 커스텀 → 갱플랭크 → 커스텀 화면(증강 그리드, 검색·전환·저장·편집 버튼)이 정상 로드됐다.
    나가기 → 종료 → 홈 복귀.
13. `xcrun simctl openurl … "augmentlab://arena?championId=Garen"` → **Unmatched Route /
    Page could not be found.**

## Findings

1. **가로 화면에서 `orca emulator tap` 좌표가 세로 기준이다.** `ax` 는 가로 화면을 가로 기준
   0..1 로 돌려주는데, `tap` 은 기기(세로) 기준으로 받는다. 아이템 선택 화면에서 ax 좌표 그대로
   저장(✓)을 눌렀더니 반대편 나가기(✕)가 눌려 "저장하지 않고 나갈까요?"가 떴다. 가로 화면에서는
   `tap (1 − y) x` 로 바꿔 찍어야 맞는다. 드래프트 카드는 화면 중앙이라 변환 없이도 맞아서 한동안
   티가 나지 않는다.
2. 시뮬레이터에는 원래 아레나 빌드가 없었다(칼바람 20 · 클래식 11). 그래서 필터는 직접
   심은 데이터로 확인했다. 같은 시나리오를 `scripts/check-build-storage.ts` 5번 assert 로도 남겼다.
