# 증강 모드 분리(칼바람 / 클래식) + 카드 설명 압축 — 시뮬레이터 검증

- **날짜**: 2026-08-20
- **Verdict**: ✅ **PASS**
- **환경**: iPhone 17 Pro (iOS 26.5), Expo dev client + Metro(:8091), 다크 모드, 한국어

## 배경 — 직전 작업의 오류를 되돌린 건

같은 날 앞선 작업에서 CDragon `cherry-augments.json` 전체를 훑어 "앱에 없는 증강 57개"를
칼바람 풀에 넣었다. **이게 틀렸다.** 대부분이 칼바람 나락이 아니라 **아수라장 클래식 스타일**
전용이라 칼바람을 굴려도 나오지 않는 증강이었다. `cherry-augments.json`에 모드 구분 필드가
없어서 걸러낼 수가 없었던 것이 원인이다.

**모드를 가르는 정답 파일을 찾았다** — `v1/augment-lists.json`. `modeName`별 증강 풀이 들어 있다.

| modeName | 앱 모드 | 개수 |
| --- | --- | --- |
| `KIWI` | `aram` — 칼바람 나락 아수라장 | 220 |
| `KIWI_JADE` | `classic` — 아수라장 클래식 스타일 | 188 |
| `CHERRY` | 아레나(별도 관리) | 44 |

`KIWI`가 칼바람이라는 근거는 데이터가 스스로 말해줬다. 앱의 기존 222개 중 **217개가 `KIWI`**인데,
잘못 넣은 신규 57개는 `KIWI`에 **단 2개**뿐이었다. 그리고 그 2개가 정확히 사용자가 "남겨라"고
지목한 **갈라진 하늘 업그레이드 · 굶주린 히드라 업그레이드**였다.

## 변경 요약

| 항목 | 결과 |
| --- | --- |
| 증강 총계 | 279 → **280개** (칼바람·클래식 양쪽 풀에 있는데 앱에 없던 `재장전` 1건 추가) |
| 모드 분류 | 칼바람 **220** · 클래식 **187** · 미출시 **36** (두 모드가 162개를 공유) |
| 매칭 키 | 전 항목에 `augmentNameId` 저장 (미확보 1건: `특기 빼면 시체` — CDragon에 없음) |
| 설명 길이 | 최대 170자 → **126자**, 130자 초과 0건 |
| 카드 폰트 | `adjustsFontSizeToFit` **제거** → 모든 카드가 같은 크기 |
| 카드 크기 | 화면 세로의 56% → **65%** (칼바람·아레나 공통) |

**미출시 36건은 지우지 않고 `modes: []`로 남겼다.** 뽑기에는 안 나오지만 데이터는 보존되어,
나중에 실제로 출시되면 태그만 바꾸면 된다. 과거 빌드가 참조할 수도 있어 조회용
`useAugments()`는 여전히 전체를 반환한다 — 뽑기 풀만 `useAugmentPool('aram')`으로 거른다.

## 이번에 드러난 함정 — 동명이인 115쌍

CDragon에는 이름이 같은 증강이 **115쌍** 있다(`ARAM_ADAPt` vs `ADAPt`처럼). 한쪽만 모드 풀에
속한다. 지금까지 스크립트가 이름으로 매칭했기 때문에, **어느 쌍둥이가 걸릴지가 CDragon 순회
순서에 달려 있었다.** 아이콘·수치·모드가 전부 이 매칭에 물려 있어 여기가 틀리면 전부 틀린다.

`tag-augment-modes.mjs`는 **풀 소속을 이름보다 먼저 본다**(KIWI → KIWI_JADE → CHERRY → 아이콘 →
이름). 이 순서로 돌린 결과 풀·아이콘으로도 못 가린 모호 건은 **0건**이었다.

아이콘도 다시 맞췄다. 다만 **generic으로 퇴보시키지 않는다** — CDragon 값이
`GenericAbilityAugmentIcon*`이면 앱에 들어 있는 개별 아이콘을 그대로 둔다. 실제로 교정 2건
(`날쌘걸음`·`연쇄 반응`, rarity 변경에 따른 generic 색 교체)과 유지 3건(빵과 버터/치즈/잼)이 나왔다.

## Findings

- **PASS — 모드 분리.** 칼바람 풀이 `KIWI` 220개와 정확히 일치한다. 클래식 전용·미출시 증강은
  뽑기에서 완전히 빠졌다.
- **PASS — 지목한 2건 유지.** 갈라진 하늘 업그레이드·굶주린 히드라 업그레이드가 `modes: ['aram']`이다.
  데이터가 사용자 판단과 일치했다.
- **PASS — 폰트 고정.** 카드마다 글자 크기가 달라지던 문제가 사라졌다. 길이는 데이터에서 맞춘다.
- **PASS — 설명 잘림 없음.** 최장 126자가 전부 표시된다.
- **회귀 1건 발견 후 처리** — 폰트 자동 축소를 없앤 탓에 **아레나에서 `불여우` 설명이 잘렸다.**
  아레나 카드도 65%로 키우고, 130자를 넘던 아레나 증강 3건(`광대 대학`·`피를 나눈 형제`·`감바 모루`)을
  압축했다. `피를 나눈 형제`에는 수치가 빠져 "5초에 걸쳐 **의** 물리 피해"로 깨진 문장도 있어 함께 고쳤다.
  아레나 최장 129자, 130자 초과 0건.
- `npx tsc --noEmit`, `npm run lint` 통과.

## 남은 것

- **미출시 36건**: 어느 모드 풀에도 없다. 실제 출시되면 `tag-augment-modes.mjs`를 다시 돌리는 것만으로
  태그가 붙는다. 검수 페이지의 `미출시만` 필터로 확인할 수 있다.
- **클래식 화면은 아직 없다.** 데이터와 `useAugmentPool('classic')` 훅까지만 준비했다 —
  사용자가 "추후에 기능 추가"라고 한 부분이다.
- **`특기 빼면 시체`** 1건은 CDragon에서 이름으로 찾지 못해 `augmentNameId`가 비어 있다.
  미출시로 분류되어 뽑기에는 영향이 없다.
- 아레나 증강 데이터에는 아직 `augmentNameId`·`modes`가 없다(타입상 옵셔널). 아레나는
  `CHERRY` 풀로 같은 방식을 적용할 수 있지만 이번 범위 밖으로 두었다.
