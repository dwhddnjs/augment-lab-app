# 클래식(아수라장 클래식 스타일) 모드 추가

- **일시**: 2026-08-21
- **판정**: ✅ PASS
- **환경**: iPhone 17 Pro 시뮬레이터(iOS 26, 402×874pt), Debug 빌드(headless xcodebuild 18s),
  Metro `http://172.30.1.77:8081` (워크트리 cwd 확인), DDragon `16.16.1`

## 무엇을 넣었나

칼바람·아레나에 이어 세 번째 모드. 플로우·UI는 칼바람과 같고 **증강 풀 / 라운드 수 / 아이템**만 다르다.

- 증강: `useAugmentPool('classic')` — 데이터는 커밋 `2092f7d`에서 이미 태깅돼 있어 배선만 함(187개)
- 라운드: 진입 시 "바론한테 간식 10개를 주셨나요?"로 **4 또는 5**
- 아이템: **새로 수급함**. 아래 참고

## 아이템은 진짜로 없었다 — 레트로 세트였다

클래식은 협곡 아이템을 쓰지 않는다. **시즌 초기 레트로 아이템 세트**(`77xxxx` id)를 쓴다.
앱의 `items.{ko,en}.json` 254개(map 11)에는 한 개도 없었다.

정답지는 게임 bin — 아레나 증강 수치에 `map30.bin.json`을 쓰는 것과 같은 구조다:

```
https://raw.communitydragon.org/latest/game/data/maps/shipping/map453/map453.bin.json
Maps/Shipping/Map453/Modes/JADE
  ├ itemLists[]   → GameModeItemList.mItems   : 상점 150
  └ mItemShopData → ItemShopGameModeData
                     .CompletedItems          : 완성 81
```

- 맵 453 = **"Classic Rift"**, `mapStringId` = `JD` (= KIWI_**JD**). CDragon `v1/maps.json`에서 확인.
- **DDragon 의 `maps` 필드는 믿을 수 없다.** map 453 에 현대 협곡 아이템까지 `true` 로 달려 있어
  무한의 대검이 `3031`·`773031` 두 벌로 잡힌다. bin 의 상점 목록만이 실제 진열이다.
- 해시 키(`{7d7e7c08}` 등)는 패치마다 바뀔 수 있어 하드코딩하지 않고 JADE 노드에서 포인터를 따라간다.
- 아이콘은 DDragon `16.16.1`에 전부 존재(HTTP 200). **`16.11.1`에는 403** — 그래서 버전을 올렸다.

## 발견

1. **아레나 상점에 레트로 신발이 샐 뻔했다 — 수정함.**
   `useItems()`에 클래식 150개를 이어 붙이자 `arena-shop.tsx`의 `bootsPool`이
   태그(`Boots`)로만 걸러서 레트로 신발 8종(광전사의 군화·닌자의 신발 등)이 아레나 상점에 들어왔다.
   한 곳만 막지 않고, 증강이 이미 쓰던 패턴(`useAugments` 조회 / `useAugmentPool` 뽑기)을
   아이템에도 그대로 옮겨 **`useItems`(조회) / `useItemPool(mode)`(진열)** 로 갈랐다.
   아레나 신발 풀은 수정 전후 7개로 동일(아레나가 쓰던 신발이 모두 `aram-item-ids`에 있어 손실 없음).

2. **레트로 아이템은 스탯 단위가 다르다.**
   현대 아이템의 "기본 체력 재생 100%"는 챔피언 기본 재생에 곱하는 **비율**인데,
   레트로의 "5초당 체력 재생 10"은 **절대값**이다. 같은 키에 담으면 10배로 곱해진다.
   `hpregenFlat` / `mpregenFlat` 키를 따로 두고 `(base + flat) * (1 + percent)` 로 합산했다.
   구버전 쿨감(`재사용 대기시간 감소`)도 스킬 가속과 계산식이 달라 `cdr` 키를 새로 뒀다.
   파서 정규식도 앞자리 숫자를 포함하도록 고쳐야 "5초당 체력 재생"이 "초당 체력 재생"으로 잘리지 않는다.
   이 정규식 변경이 기존 254개 아이템 데이터를 흔들지 않는지 `git diff`로 확인 — **변경 0**.

3. **클래식 아이템 12종이 어느 필터 탭에도 안 걸렸다.** 구버전 태그가 현대 규칙과 어긋난다
   (무라마나 `[OnHit]`, 대천사의 포옹 `[]` 등). `ITEM_CATEGORIES`에 19건을 명시 분류해 0건으로 만들었다.

4. **DDragon 버전을 16.11.1 → 16.16.1 로 올렸다.** 레트로 아이콘이 16.11.1에는 없다(403).
   부수효과로 프리웜 플래그 키가 바뀌어 기존 사용자도 1회 재프리웜한다(설계대로).
   협곡 254개 아이템 자체의 재수집은 이번 범위 밖 — 별개 작업으로 남긴다.

## 함정 메모 (verify skill 보강거리)

- **시뮬레이터 스크린샷의 세로 배율은 가로와 같다(919×1879 이미지 → 0.4374).**
  `874/1879 = 0.4651` 로 잡으면 세로가 7% 부풀어, 카드처럼 큰 타깃은 맞지만
  하단의 44pt 원형 글래스 버튼(저장·드로어)은 전부 빗나간다. 한동안 "저장 버튼이 죽었다"고
  오진했는데 순전히 좌표 실수였다 — 실제로는 정상 동작.
- **expo dev-launcher FAB가 헤더 우측 버튼(✓)을 정확히 덮는다.** 탭이 dev 메뉴로 먹힌다.
  메뉴의 `Tools button` 토글로 끄거나, 딥링크(`augmentlab://arena?championId=…`)로 우회한다.
- 화면만 보고 판단하지 말 것 — 저장 여부는 AsyncStorage 원본으로 대조했다
  (`<container>/Library/Application Support/com.augmentlab/RCTAsyncLocalStorage_V1/`).
  덕분에 "저장이 안 됐다"를 추측이 아니라 사실로 확정했다.
- 클린 설치 검증 전에 저장소 디렉터리를 통째로 복사해 두면 검증 후 빌드·설정을 그대로 되돌릴 수 있다.
  (검증 후 칼바람 9 + 클래식 1 = 10개 복구, 로케일 ko·다크 유지 확인)
