# iOS 전용 전환 + `draft` → `aram` 리네임 — 시뮬레이터 검증

- **날짜**: 2026-07-10
- **Verdict**: ✅ **PASS**
- **대상 변경**: [계획 문서](../plans/2026-07-10-ios-전용-전환-및-draft-aram-리네임.md)
- **환경**: Xcode 26.5 / iPhone 17 Pro (iOS 26.5) 시뮬레이터 / `npx expo run:ios` 네이티브 debug 빌드

> iOS 26 시뮬레이터를 고른 이유: `NativeTabs`(리퀴드글래스 탭바)와 `glass-button`의 SwiftUI
> `glassEffect` 는 iOS 26+ 에서만 렌더된다. 그 미만을 고르면 폴백 경로(`custom-tabs`,
> `glass-button-fallback`)만 보게 되어 정작 검증하려는 코드가 실행되지 않는다.

## 검증한 것

Android 제거 과정에서 **플랫폼 분기 파일 5쌍을 iOS 단일 파일로 접었다.** 정적 검사로는
"import가 깨지지 않았다"까지만 알 수 있고, 승격된 파일이 실제로 렌더되는지는 앱을 띄워야 안다.
`draft` → `aram` 리네임도 라우트 문자열이 런타임에 해석되므로 마찬가지다.

## Steps

## 발견한 버그와 수정

### 1. `/aram-items` 에 나가기 경로가 없었다 — 수정함

**증상**: 아이템 선택 화면에는 저장(체크) 버튼만 있었다. 원래는 Android 하드웨어 백이 유일한
탈출구였는데, iOS 전용 전환으로 `useHardwareBack`을 제거하면서 그 경로가 사라졌다.
iOS에서는 `gestureEnabled: false` + `headerShown: false` 라 스와이프 백도 막혀 있다.
즉 **저장하지 않고는 이 화면을 빠져나갈 수 없다.**

정적 분석으로는 "iOS엔 원래 없던 경로니 회귀 아님"으로 넘어갔지만, 실제로 굴려보니
사용자가 갇히는 게 분명했다.

**수정** (`src/features/items/screens/item-select-screen.tsx`):
헤더 좌측에 `GlassButton systemImage="xmark"` 를 추가하고, 확인 Alert 후
portrait로 되돌린 다음 홈으로 나가게 했다(빌드는 저장하지 않는다). 제거했던
`exitConfirm`/`exitOk`/`exitCancel` 로케일 키도 복원했다.

**재검증**: 나가기 버튼 노출 → Alert("저장하지 않고 나갈까요?") → "나가기" → portrait 복귀,
홈 도착, **빌드 목록에 미저장** 확인.

### 2. `themed-text.tsx` 의 사전 존재 타입 에러 6건 — 수정함

`VARIANT_STYLES` 가 `Record<TextVariant, typeof Typography.body>` 로 선언돼 있었다.
`typeof Typography.body` 는 `as const` 때문에 `{ fontSize: 16; lineHeight: 24; fontWeight: "500" }`
**리터럴 타입**이라, `display`(48) `title`(32) 등 다른 variant를 대입할 수 없었다.

이번 변경 이전부터 있던 에러다(변경 전 stash 상태에서 재현 확인). `TextStyle` 로 넓혀 해소했다.
수정 후 `npx tsc --noEmit` **에러 0건**.

## Findings

런타임에서만 보이는 것들. 버그가 아니어도 다음 사람이 알면 좋은 것들을 적는다.

- **`/draft` 딥링크는 크래시가 아니라 expo-router의 `Unmatched Route` 화면으로 처리된다.**
  Go back / Sitemap 링크가 제공되므로 갇히지 않는다.
- **iOS 26은 커스텀 스킴 딥링크마다 "'증강 연구소'에서 열겠습니까?" 확인을 띄운다.**
  앱이 종료된 상태에서 열어도 뜬다. 자동 검증 시 매번 클릭이 필요하므로,
  일반 플로우는 딥링크보다 UI 클릭이 빠르다.
- **expo dev-client의 톱니 FAB가 챔피언 선택 화면의 시작(체크) 버튼을 정확히 덮는다.**
  개발 빌드 한정이라 제품 이슈는 아니다. 이 화면의 헤더 우측 히트박스를 손볼 때 기억할 것.
- 남아 있는 폴백(`custom-tabs.tsx`, `glass-button-fallback.tsx`)은 **Android용이 아니라
  iOS 26 미만용**이다. 이름만 보고 지우지 말 것.
- `typedRoutes` 타입(`.expo/types/router.d.ts`)은 `expo export`로는 생성되지 않는다.
  `expo start`를 잠깐 띄워야 생긴다. 이걸 만들고 나서야 tsc가 `/aram` 라우트 문자열을 검증한다.
  (생성 후 확인: `/aram`, `/aram-items` 등록 · `draft` 0건)

## 검증 절차의 한계 (다음 사람에게)

- `xcrun simctl` 에는 tap 명령이 없다. `osascript` 의 `click at` 도 실제 CGEvent를 만들지 않아
  먹지 않는다. **`cliclick` + macOS 접근성 권한**이 필요하다. `idb-companion`은 Xcode 26에서
  동작하지 않았다.
- 좌표 매핑에서 시뮬레이터 창의 베젤은 **상하 비대칭**이다(상단 71 = 베젤 27 + 타이틀 44, 하단 27).
  이걸 균일하게 가정하면 클릭이 조용히 빗나간다 — 실제로 이번에 한 번 겪었다.
- 이번 세션 중 FAB 드래그 직후의 "dev menu 닫기" 클릭이 메뉴가 없던 탓에 챔피언 그리드에
  떨어져 **선택이 갈리오 → 나미로 바뀌었다.** 앱 버그가 아니라 조작 아티팩트다.
  조작 후에는 스크린샷으로 상태를 확인하고 다음 단계로 갈 것.
