# 클래식·데이터관리 추가 후 구조 정리 — 검증

- 날짜: 2026-08-25
- 기기: iPhone 17 Pro 시뮬레이터 (다크/라이트, ko/en 모두)
- 대상 커밋: `853036d refactor: 클래식·데이터관리 추가 후 구조 정리`
- 성격: UI·동작 무변경 리팩터링. **회귀가 없는지**만 본다.

## 변경 요약

죽은 코드 9파일 삭제(Supabase 원격 저장 3, Expo 템플릿 잔재 4, glass-chip 1,
item-text 1), 의존성 2개 제거, 중복 3건 통합, 화면 파일 2개 분리.
자세한 내용은 커밋 메시지와 `docs/plans/2026-08-25-클래식-데이터관리-구조정리.md`.

## 관찰

번들: `iOS Bundled 7487ms (2048 modules)` — 캐시 비운 상태에서 에러·경고 0.

**홈 모드 세그먼트** (`mode-switch.tsx` 로 분리한 부분 — 가장 위험했던 곳)
- 칼바람→클래식(한 칸), 클래식→아레나(한 칸), 세그먼트 pill 이 부드럽게 슬라이드하고
  라벨이 민트로 물든다. 목록은 이동이 끝난 뒤 교체 — 분리 전 동작 그대로.
- pill 너비가 정확히 트랙 1/3. `trackWidth` shared value 가 컴포넌트로 내려갔지만
  측정 타이밍 문제(첫 프레임 왼쪽 튐)는 재현되지 않았다.
- 스크롤로 세그먼트가 사라지면 헤더 우측 원형 토글이 등장. 원이 활성 아이콘(체스룩)
  뒤에 정확히 자리잡고 튀지 않는다. 토글로 아레나 전환 → 목록 교체 확인.
- 다시 위로 스크롤해 세그먼트가 remount 됐을 때도 pill 이 아레나 자리에 그대로.
  두 컨트롤이 `progress` 하나를 공유하는 구조가 유지된다.
- 마이페이지를 다녀와도 선택 모드가 보존된다(`lastMode` 모듈 스코프).

**클래식 드래프트**
- `+` 오버레이 3버튼 stagger 정상 → 클래식 선택 → 챔피언 선택 모달.
  아레나가 아니므로 "용기" 물음표 칸이 없다 — `parseGameMode` 가 'classic' 을
  제대로 통과시킨다는 뜻(삼항을 함수로 바꾼 부분).
- 바론 간식 알럿 → "예" → 라운드 인디케이터 **0/5**. 5라운드 반영 정확.
- 픽 3회 진행하며 실버→골드로 희귀도가 바뀌는 것 확인. 리롤 1회: 카드가 같은 골드
  희귀도로 교체되고 해당 리롤 버튼만 흐려진다. 나머지 두 장은 그대로.
- 픽 현황 드로어: 갈리오 / 탱커·마법사 / 체력 600·이속 340·공격력 59·방어력 24·마저 32,
  증강 3/6(=rounds+1 슬롯).

**아이템 선택** (`use-item-select.ts` 로 분리한 부분)
- 5픽 완료 후 자동 이동. 헤더 "아이템 선택 0/6", 8열 그리드, 필터 사이드바 8탭,
  트레이 6칸, 우측 챔피언+스탯 패널 — 레이아웃 그대로.
- 아이템 2개 선택 → 카운터 2/6, 셀에 민트 테두리+체크 배지, 트레이 좌측부터 채워짐,
  우측 합산 스탯이 즉시 반영(체력 980 (+380) / 주문력 70 (+70) / 마저 77 (+45)).
  `CELL_GAP` 을 item-grid 에서 export 해 훅이 쓰도록 바꿨는데 셀 크기 동일.
- 신발 필터: 레트로 신발 7종만 남고 선택·스탯은 유지. 협곡 아이템이 새지 않는다.

**빌드 상세**
- 저장 → portrait 복귀(회전 잔상 없음) → 상세 직행.
- 챔피언 헤더에 클래식 배지(체스룩), 증강 5개, 각 카드 좌측 희귀도 라인.
- 아이템 행: "루비 시야석 체력 380", "심연의 홀 주문력 70 · 마법 저항력 45" +
  고유 효과 설명. **`<stats>` 블록 중복 없음** — `cleanItemDescription` 을
  `item-text.ts`→`text.ts` 로 옮기고 이름을 나눈 뒤에도 동작 동일.
- 합산 스탯 패널 수치가 아이템 화면과 일치. 스크롤 시 헤더 글래스+타이틀 페이드인.

**마이페이지 · 데이터 관리** (default→named export 로 바꾼 화면)
- 라우팅 정상. insetGrouped List, 테마·언어 Picker, 데이터 관리 진입 모두 그대로.
- 백업: 공유 시트에 `augment-lab-2026-08-25` (5KB, .alab) + "파일에 저장" 노출.
  방금 저장한 빌드가 포함된 크기다. 시트는 저장하지 않고 닫았다.
- 복원·초기화는 사용자 데이터를 지우므로 누르지 않았다(화면·문구만 확인).

**테마 · 로케일**
- 라이트: 세그먼트 트랙 흰색 + 연한 민트 pill, 홈 카드 scrimLight 로 하단 띠가
  절제되어 splash 가 밝게 보인다. 마이페이지 흰 카드.
- 영어: 세그먼트가 ARAM / Classic / Arena. mode-switch 안에서 `MODE_LABELS` 를
  직접 번역하도록 바꿨는데(화면 t 사전 spread 제거) 라벨 동일.
  My Builds / Home / My Page / Galio the Colossus 까지 정상.
- 검증 후 다크·한국어로 되돌려 두었다.

## 남은 것

- 검증 과정에서 만든 클래식 빌드 1개(2026.8.25 갈리오, 증강 5·아이템 2)가 시뮬레이터
  데이터에 남아 있다. 실기기가 아니라 지우지 않았다 — 필요하면 홈에서 길게 눌러 삭제.
- 아레나 화면 내부는 이번 정리 범위 밖(import 2줄만 바뀜). 아레나 픽/상점 플로우는
  돌려보지 않았다.
