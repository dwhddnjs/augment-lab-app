# 빌드 카드 하단 scrim — 라이트 모드 톤 완화

- 날짜: 2026-08-25
- 기기: iPhone 17 Pro 시뮬레이터 (라이트 모드, ko)
- 변경: `HeroOverlay.scrim0~3` → `scrimDark`/`scrimLight` 두 세트로 분리.
  라이트는 0 / 0.3 / 0.55 / 0.7 (기존 0 / 0.55 / 0.85 / 0.96).

## 관찰

- 홈 "내 빌드" 목록을 라이트 모드로 스크롤. 갈리오·갱플랭크 카드 모두 하단
  띠가 순검정에서 반투명으로 내려가, 밝은 배경과 맞닿는 경계가 덜 튄다.
- 흰 제목("갈리오")·회색 부제("위대한 석상")·증강/아이템 타일 모두 그대로 읽힌다.
  갱플랭크처럼 splash 하단이 밝은 경우에도 대비 유지.
- 다크 모드 값은 건드리지 않아 기존 톤 그대로.

## 남은 것

- splash 자체가 어두운 챔피언은 여전히 하단이 어둡게 보이나, 이는 이미지 원본
  탓이지 scrim 탓이 아님.
