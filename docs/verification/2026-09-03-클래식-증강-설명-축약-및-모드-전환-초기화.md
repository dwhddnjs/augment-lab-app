- 날짜: 2026-09-03
- 기기: iPhone 17 Pro 시뮬레이터 (iOS 26.5), Debug 빌드 + Metro
- 대상:
  1. 클래식 증강 5건 설명 축약(`augments.{ko,en}.json`) + 검수 페이지 "설명 축약" 배지
  2. 커스텀 화면(`/custom`) 모드 세그먼트 전환 시 담은 증강·아이템 **전부** 비우기

## Verdict

**PASS**

## 사전 확인

- `node scripts/check-augment-data.mjs` 통과(ko/en 모두 130자 이하).
- `npx tsc --noEmit` 통과, `npm run lint` 통과.
- 네이티브 변경 없음 — 기존 설치본에 Metro 번들만 갈아끼워 실행.
- 화면이 landscape 고정이라 시뮬레이터 프레임은 portrait 그대로 두고 좌표를 회전 변환해
  주입했다(`portrait_x = 402 - landscape_y`, `portrait_y = landscape_x`, point 기준).

덜어내기)이라면 하나도 지워지지 않았을 조합이라, 여기서 0으로 떨어지는 것이 곧 변경의 증거다.

## 데이터 변경 5건 (모두 `modes:["classic"]`)

| 증강 | 바뀐 점 |
|---|---|
| 단호함 | 수치·중첩·재사용 대기시간 제거 |
| 원상복구 | 재시전 폭발/귀환만 남기고 계수 제거 |
| 공허 돌진 | 범위·계수·둔화 수치 제거 |
| 도란 열혈 팬 | 중첩당 125% 부여로 정리, 판매 불가 문구 제거 |
| 광대 대학 | 속임수 + 암습 지속 효과로 정리 |

포로 발사기·엄마 찾는 아기 고양이는 요청 문구가 기존 데이터와 같아 손대지 않았다.

`docs/augment-desc-trimmed.json` 에 위 5개 id 를 추가해 검수 페이지에서 **"설명 축약" 배지**가
붙는다(71 → 76건). 검수 페이지는 카드를 클라이언트 JS 로 그리므로 정적 HTML grep 이 아니라
페이지에 임베드된 `DATA` 배열의 `trimmed: true` 로 확인했다.

## 확인하지 못한 것

- 드로어의 **퀵모드 토글은 합성 탭에 반응하지 않았다**(@expo/ui SwiftUI `Toggle`). 좌표는 맞았고
  같은 좌표계의 세그먼트 Picker·backdrop 탭은 정상 동작했다. 담기는 롱프레스 드래그로 대신했다.
- 한글은 `simctl` 텍스트 주입이 안 돼(ASCII 만 가능) 검색 대신 정렬·필터·스크롤로 카드를 찾았다.
- en 설명은 130자 한도만 검사했고 시뮬레이터에서 영어 로케일로는 굴리지 않았다.
