# 데이터 백업 · 복원 · 초기화 — 시뮬레이터 검증

- **날짜**: 2026-08-20
- **Verdict**: ✅ **PASS**
- **환경**: iPhone 17 Pro (**iOS 26.5**), dev-client debug 빌드 (`xcodebuild` + `simctl install`, Metro :8082)

마이페이지에 **데이터 관리** 화면을 추가하고 `.alab` 백업 파일로 로컬 데이터를
내보내기/되돌리기/지우기를 붙였다. 앱을 지우면 AsyncStorage가 통째로 날아가고
로그인이 없어 복구 수단이 전혀 없던 문제를 막는 것이 목적.

## Findings

### 파일명 날짜가 UTC였다 (수정함)
3번에서 KST 04:57에 백업했더니 `augment-lab-2026-08-19.alab` — `toISOString().slice(0,10)`이
UTC 기준이라 로컬 날짜보다 하루 빨랐다. `buildFileName(date: Date)`으로 바꿔 로컬 연·월·일을
쓰도록 고치고, fast refresh 후 다시 백업해 **`augment-lab-2026-08-20`** 로 나오는 것을 확인했다.
(`exportedAt` 필드는 정확한 시각 기록이므로 ISO/UTC 유지.)

### 공유 시트 dismiss 직후 첫 탭이 씹힌다 (동작상 문제 없음)
공유 시트를 스와이프로 닫은 직후 곧바로 "데이터 복원"을 누르면 반응이 없고, 한 번 더 누르면 정상
동작했다. `busy` 잠김이 아니라 시트 dismiss 애니메이션 중 터치가 먹은 것 — 실사용 속도에서는
문제되지 않아 그대로 뒀다.

### 초기화 범위
`builds:v1`·`theme:v1`·`locale:v1`만 지우고 이미지 프리웜 완료 플래그(`prewarm:done:*`)는 남긴다.
캐시 성격이라 지우면 재설치도 아닌데 전체 이미지를 다시 받게 되기 때문. 6번에서 의도대로 확인했다.
