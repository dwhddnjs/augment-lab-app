# 미사용 코드·에셋·의존성 정리 + 티어리스트 구조 분리

- 날짜: 2026-09-19
- 기기: iPhone 17 Pro (iOS 26.5, 402×874 pt)
- 빌드: 네이티브 재빌드. 의존성을 뺐으므로 `expo prebuild` → `pod install`(ExpoDevice 제거)
  → `xcodebuild` → `simctl install`. JS 는 이 워크트리의 Metro 로 받았다.
- **Verdict: PASS**

## 무엇을 바꿨나

**지운 것**

- 에셋: `assets/images/*`(Expo 템플릿 로고·탭 아이콘·favicon 등 17개), `assets/expo.icon/`.
  앱 아이콘·스플래시는 `assets/store/` 것을 쓰고 있었다.
- 라우트: `(tabs)/(community)` — 탭 트리거가 주석 처리돼 어디서도 갈 수 없던 "곧 열려요" 화면.
- 의존성: `expo-device`·`expo-status-bar`·`react-dom`·`react-native-web`(웹 미지원),
  `expo-symbols`(직접 import 없음 — expo-router 의존성으로는 여전히 설치된다).
  `package.json` 의 `web`·`reset-project` 스크립트, `app.json` 의 `web`·`android` 블록.
- 스크립트: `reset-project.js`(템플릿), `gen-synergies.mjs`(시너지 기능 제거됨),
  `fill-augment-{icons,ko}.mjs`(1회성, `tag-augment-modes`·`apply-mayhem-patch` 가 대체),
  `fetch-data/{index,fetch-augments}.ts`(존재하지 않는 `src/data/` 에 위키 원본을 덮어쓰던 경로).
- `supabase/`(CLI 캐시 `.temp` 포함)·`.env.example` — 앱에 Supabase 클라이언트가 없다.
- 코드: 템플릿 `AnimatedIcon`, `use-color-scheme` 재수출, 테마 토큰(`Fonts`·`Brand.logoBg*`·
  `glass.sheen/rim*`·`accent.hover/pressed`·`Typography.code`·`Elevation.level0/3`),
  `ThemedText` 의 `code`/`link` 변형, `ThemedView.elevation`, `GlassSurface` 의
  `intensity`/`isInteractive`/`tintColor`/`glassStyle`(전부 기본값 `regular` 만 쓰였다),
  `RemoteImage.transition`, 안 쓰는 i18n 키·export(`getLocale`·`getThemePreference` 등).

**고친 것**

- `data:refresh` → `fetch-ddragon.ts` 가 없는 `src/types/*` 를 import 하고 없는 `src/data/` 에
  쓰던 것을 각 feature 의 `data/` 와 `src/lib/version.json` 으로.
- 칼바람 드래프트의 증강 아이콘 프리페치가 `large`·`small` 만 받고 실제 두 번째 폴백인 `base` 를
  건너뛰었다. `ddragon.ts` 에 `augmentImageUrls()`(폴백 순서 그대로의 주소 목록)를 두고 로더·
  첫 설치 프리웜·드래프트 프리페치가 모두 이걸 쓴다. 증강 282개 전부 이전 로직과 같은 URL 이
  나오는지 스크립트로 대조했다.
- 루트 레이아웃이 `useTheme` 와 다른 폴백으로 테마 모드를 따로 계산하던 것을 `useTheme().mode` 로.
- 챔피언 선택의 아이콘 전용 헤더 버튼에 안 쓰이던 `cancel`/`start` 문구를 VoiceOver 라벨로.

**티어리스트 분리** (`features/tierlist/`)

- `types.ts` — `Tier`·`TierRow`·`TierItem`·`AugmentGroup` 등 타입을 `tiers.ts` 에서 분리.
- `hooks/` — `use-tier-colors`, `use-tierlist-items`(로케일별 id→아이템 Map 을 모듈 로드 때 1회),
  `use-augment-groups`(증강 풀 조인·희귀도 그룹), `use-staged-expand`(단계 펼침),
  `use-scroll-top-anchor`(large title 아래 진짜 최상단 복귀).
- `components/` — `TierMark`(그라데이션 바탕 + 등급 글자, 기존 `TierGradient` 대체),
  `TierlistChampionCell`, `TierlistChampionHeader`, `TierlistAugmentSection`, `TierlistItemSection`.
- 화면 두 개는 조립만 남았다: 목록 224 → 152줄, 상세 373 → 123줄.

## Steps

1. 새 빌드 설치 후 실행 → 스플래시 오버레이가 걷히고 홈 "내 빌드". 탭은 메인 / 티어리스트 /
   마이페이지 / + 그대로. 제거한 네이티브 모듈로 인한 크래시 없음.
2. 티어리스트 탭 → S 배너(보라 그라데이션 캡슐, 흰 "S"), 2열 셀(초상화 테두리 등급색,
   승률 민트 + 픽률). 섹션 S 26 · A 26 · B 18 · C 51 · D 51 — `check-tierlist` 출력과 같다.
   셀이 이제 VoiceOver 에 `button "야스오, 56.6% · 픽 10.9%"` 로 읽힌다.
3. 홀수 티어(C·D) 마지막 줄 셀 폭 → **처음엔 0.470, 다른 셀은 0.450 이었다(Findings 1).**
   수정 후 재시작해 다시 재니 C 마지막(다리우스)·D 마지막(바드) 모두 0.4502 로 같다.
4. 목록을 당겨 검색바 노출 → `zzz` 입력 → "검색 결과가 없습니다" + 출처 문구
   "aram.gg 집계 · 패치 16.18 · 2026-09-14 기준"(치환 정상). 닫기 → 전체 목록 복귀.
5. 야스오 → 상세 모달: 헤더(S 배지 · 야스오 · "전사 · 암살자" · "승률 56.6% · 픽률 10.9%"),
   증강 프리즘/골드/실버 각 6장(카드 아이콘 아래 등급 배지, 우측 선 등급색), "모든 증강 보기",
   아이템 제목 오른쪽 스펠 pill(아이콘 2 + 79.5%, 라벨 "추천 스펠, 픽률 79.5%"),
   빌드 순서 6개 · 상황별 아이템 10개 아이콘.
6. 아래로 스크롤 → "모든 증강 보기" → 화면이 맨 위로 돌아가 야스오 헤더가 보이고, 그룹이
   **프리즘 50 · 골드 37 · 실버 34** 까지 붙었다. 데이터에서 직접 조인한 기대값과 같다.
   버튼은 "증강 접기"로 바뀐다.
7. 끝까지 내려 "증강 접기" → 그룹당 6장으로 돌아오고, 버튼·아이템 섹션이 화면에 남는다.
8. 닫기(✕) → 티어리스트 복귀(Findings 2).
9. `+` → 오버레이 커스텀 / 클래식 / 칼바람 → 칼바람 → 챔피언 선택. 헤더 아이콘 버튼이
   `button "취소"`, `button "시작하기"` 로 읽힌다.
10. 가렌 → 시작하기 → 가로 드래프트 "라운드 0 / 4". 라운드 박스(글라스), 카드 3장
    (사악한 정신 · 빠르고 안전하게 · 확보된 킬) 아이콘 모두 로드, 리롤 버튼 3개.
11. 나가기(✕) → "칼바람을 종료할까요?" 계속 / 종료 → 종료 → 홈 "내 빌드".
    (`handleExit` 의 수동 `useCallback` 을 걷어낸 경로.)
12. 홈 첫 카드(갱플랭크) → 빌드 상세: 상단 스플래시 + 둥근 시트, 챔피언 헤더, 칼바람 칩,
    증강 4 카드 행 정상. 뒤로 → 홈.

## Findings

1. **분리 과정에서 넣은 회귀를 검증에서 잡았다.** 덜 찬 마지막 줄의 빈 칸을 `{ flex: 1 }` 로만
   두었더니 옆 셀이 8pt 넓어졌다. 원래 빈 칸은 셀 스타일을 그대로 써서 padding(8)을 갖고 있었고,
   Yoga 는 `flexBasis: 0` 을 padding 만큼 올린 뒤 남은 폭을 나누기 때문이다. 빈 칸에 같은
   padding 을 주고 주석을 달았다. 폭 차이가 0.02(=8/402) 라 눈으로는 놓치기 쉽고, `ax` 프레임
   폭을 비교해서 찾았다.
2. 상세 모달에서 "증강 접기" 직후 닫기(✕)를 누른 첫 탭은 먹지 않았고, 두 번째 탭에 닫혔다.
   접기로 콘텐츠가 줄며 ScrollView 가 끝으로 당겨지는 중이라 탭이 스크롤 정지로 소비된
   것으로 본다. 닫기 버튼 코드는 이번에 바꾸지 않았다.
3. 파일을 고친 뒤 Fast Refresh 가 반영되지 않아 `terminate` + `launch` 로 확인했다.
4. 이번 확인에서 빠진 것: 라이트 모드, 첫 설치 프리웜(앱 삭제가 필요해 로컬 빌드가 날아간다).
   프리웜은 URL 목록 생성만 바뀌었고 결과 URL 이 기존과 같음을 스크립트로 확인했다.
   `check-tierlist` · `check-backup` · `check-build-storage` · `check-rarity-odds` 는 변경 전후 모두 통과.
