# 코드베이스 구조 정리 검증 (2026-09-03)

**Verdict: PASS**

카드 애니메이션 훅·리롤 버튼·커스텀 선택 패널을 공용화하고 로케일 데이터 훅 일곱을
하나로 합친 리팩터링. UI 픽셀을 바꾸는 게 목적이 아니었으므로 **네 화면이 리팩터링 전과
똑같이 동작하는지**를 봤다.

- 기기: iPhone 17 Pro (iOS 26.5), Metro 연결 상태에서 앱 terminate → launch
- 손댄 것: `PickCard`/`useCardPickAnim`/`RerollButton` 공용화, `SelectedPanel` 3분할,
  `useLocalizedData` 도입, 아레나 저장 effect deps 축소, 죽은 코드 3건 제거

## Steps

### 1. 홈 · 빌드 상세
- 홈 목록이 뜨고 모드 세그먼트(칼바람/클래식/아레나)와 날짜 섹션이 정상.
- 갱플랭크 빌드 상세: 스크롤에 따라 배너가 접히고 글래스 헤더 + 챔피언 이름이 페이드인.
  증강 4개(이름·설명), 아이템 5개(스탯 줄·설명), 합산 스탯(체력 2430(+1800) 등)까지 전부 표시.

### 2. 칼바람 드래프트 — 카드 애니 훅·리롤 버튼
- 가렌으로 진입. 프리즘 카드 3장 + 리롤 버튼 3개.
- **리롤**: 1번 버튼을 누르니 1번 카드만 "거신상의 용기"→"남작의 도움"으로 바뀌고(등급 유지),
  **그 버튼만** 가라앉은 표면 + 흐린 글리프로 잠겼다. 2·3번은 또렷한 채.
- **픽**: 라운드 0/4 → 1/4(첫 점이 민트로 채워짐), 새 골드 카드 3장, **리롤 예산 3개 모두 리셋**.
- 카드 설명의 "500골드"·"250골드"가 금색으로 강조 — 정규식을 한 곳으로 합친 뒤에도 그대로.
- 드로어: 가렌 아이콘·역할칩·스탯(체력 690/이속 340/공격력 69/방어력 38/마저 32),
  "증강 1/5" + 픽한 증강 1개 + 빈 슬롯 점선 4개.
- 4라운드를 완주하니 **아이템 선택 화면으로 전환**(`commitPick`의 replace 경로).
  아이템 1개 선택 시 트레이에 들어가고 우측 스탯이 이동속도 385(+45)로 갱신.
- 저장 → 세로 복귀 → 빌드 상세. 증강 4개가 뽑은 순서대로, 각 행 좌측 보더가
  프리즘(연보라)·골드(금색)·실버(회색)로 정확히 갈림.

### 3. 아레나 — 공용 PickCard 위의 별 오버레이·상점
- 챔피언 선택 첫 칸에 "용기"(물음표)가 아레나에서만 노출.
- 진입 시 "라운드 1/12" + 골드 500(금색). 실버 카드 3장, 첫 카드에 **레벨 별(★☆) 오버레이**가
  카드 상단에 그대로 얹힘 — PickCard로 갈아탄 뒤에도 위치·크기 동일.
- 리롤: 1번 카드가 "위치 변경"→"처형자"로 교체되고 그 버튼만 잠김(칼바람과 같은 거동).
- 픽 → 상점: 신발/전설급/모루 탭, 신발 7종 × 500골드, 하단 6칸 트레이.
- 신발 구매 → **골드 500 → 0**, 구매한 칸은 accent 테두리(보유), 나머지 신발은 흐려짐(골드 부족),
  트레이 첫 칸에 아이콘.
- 드로어: 증강 1(별 1개) + 아이템(신발) + 골드 배지 0.
- 나가기 → "아레나를 종료할까요?" Alert이 가로 방향 그대로 뜨고, 종료 시 세로 복귀 + 홈.
  방금 저장한 칼바람 빌드가 목록 최상단(2026.9.3)에 있음.

### 4. 커스텀 — SelectedPanel 3분할
갈리오로 진입. 분리한 세 조각이 전부 제자리:
- **챔피언 행**: 아이콘(accent 테두리) + 이름 + "탱커 · 마법사" + 정보/변경/초기화 알약 3개
  (정보=흰색, 변경=민트, 초기화=빨간 restart 글리프).
- **픽 칸 2개**: "증강 0/5"(활성, accent 테두리) / "아이템 0/6"(subtle 테두리),
  각각 "카드를 넣어주세요" · "아이템을 넣어주세요" 점선 힌트.
- **드래그&드롭**: "적응형 능력치" 카드를 길게 눌러 우측 칸으로 끌자 담김. 0/5 → 1/5,
  행에 아이콘·이름(실버 등급색)·모서리 제거 배지가 생기고, 좌측 원본 카드에는 체크 배지 + 어두운 베일.
- **칸 전환**: 비활성인 아이템 칸을 탭하니 좌측 그리드가 아이템으로, 필터 레일이 티어→클래스
  아이콘으로, 검색 플레이스홀더가 "아이템 이름을 입력해주세요"로, 헤더 토글과 칸 테두리까지
  한 번에 넘어감. 담긴 증강 행은 유지.
- **제거 배지**: x를 누르니 1/5 → 0/5로 빠지고 빈 힌트 복귀. **칸 전환은 일어나지 않음**
  (배지가 부모 행 탭을 가로챈다는 원래 동작 보존).
- 정보 → 갈리오 스탯 오버레이(체력 600/마나 410/공격력 59/방어력 24/마저 32).
- 변경 → "챔피언 변경" 시트, 8열 그리드, 현재 갈리오가 accent 테두리 + 민트 이름.
- 나가기 → "커스텀을 종료할까요? / 담은 증강과 아이템은 저장되지 않습니다." 후 홈.

### 5. 로케일 전환 — `useLocalizedData`의 최대 리스크
데이터 훅에서 `useMemo`를 걷어냈으므로 로케일 반응성이 살아 있는지 직접 확인:
- 마이페이지 → 언어 → English: 홈이 "My Builds", 세그먼트가 ARAM/Classic/Arena,
  챔피언이 Gangplank("the Saltwater Scourge")·Garen("The Might of Demacia"),
  탭바가 Home/My Page로 즉시 전환.
- 빌드 상세도 Multishot / Skilled Sniper / Erosion / Double Tap 로 전환되고 날짜가 9/3/2026(en-US).
  역할 칩 Fighter/Tank, 배지 ARAM.
- 한국어로 되돌리니 전부 원복. 재시작 없이 즉시 반영된다.

## Findings

1. **아레나 프리즘·모루 카드의 리롤 버튼이 픽 연출 중 흐려진다(opacity 0.35).**
   원래는 아레나 *증강* 카드만 이 처리를 갖고 있었고 프리즘·모루 카드는 빠져 있었다.
   공용 `RerollButton`이 증강 카드 쪽 동작을 표준으로 삼으면서 세 카드가 같아졌다.
   눌러도 소용없는 순간을 알려주는 쪽이 맞다고 보고 통일한 것 — 의도된 변화다.
2. **아레나 리롤 버튼에 눌림 피드백(opacity 0.65)이 생겼다.** 칼바람에는 원래 있었다.
3. 커스텀 챔피언 선택에서 dev-client 톱니 FAB가 첫 칸(가렌)을 덮어 탭이 두 번 먹혔다.
   앱 버그가 아니라 dev 빌드 특성 — 겹치지 않는 칸(갈리오)으로 우회했다.

## 검증하지 못한 것

- **애니메이션 곡선과 등장 순서.** 정지 프레임으로는 판정할 수 없다. 카드가 교체되고
  라운드가 넘어간다는 것까지만 확인했다. 곡선 자체는 칼바람·아레나가 쓰던 두 벌의 코드가
  글자 그대로 같았고 그것을 `PickCard` 한 파일로 합친 것이라, 동일성은 코드 수준에서 보장된다.
- **픽 연출 380ms 도중 나가기를 눌렀을 때의 레이스.** 이번 수정의 표적(타이머가 unmount 뒤
  살아남아 `/aram-items`로 밀어내던 문제)이지만, MCP 탭 한 번의 왕복이 380ms보다 길어
  손으로 재현할 수 없었다. `useCardPickAnim`이 unmount에서 `clearTimeout` 하도록 고친 것으로만
  보장한다.

### 쓰기 실패 경로 — `scripts/check-build-storage.ts`

시뮬레이터에서는 AsyncStorage 쓰기 실패를 만들 수 없다. AsyncStorage 가 node 에서 web 구현
(`window.localStorage`)으로 떨어진다는 점을 이용해, `window` 를 세우고 그 `setItem` 만 던지게
해서 실제 `build-storage` 를 그대로 돌렸다.

- 정상 저장 → 캐시 1 / 디스크 1
- **쓰기 실패 저장 → 예외가 호출부까지 오고 캐시는 1 그대로**(유령 빌드 없음)
- **쓰기 실패 삭제 → 예외가 오고 캐시에서도 지워지지 않음**(되살아나는 빌드 없음)
- 정상 삭제 → 캐시 0 / 디스크 0

이 체크가 진짜 회귀를 잡는지도 확인했다. 롤백 두 줄을 임시로 걷어내고 돌리니
`실패한 저장은 캐시에 남지 않는다 … 2 !== 1` 로 정확히 걸렸고, 되돌리니 다시 통과했다.

### 시뮬레이터 — 정상 경로가 막히지 않았는지

수정 셋 다 "실패했을 때"를 다루므로, 정작 위험한 건 **정상 경로를 막는 것**이다. 그쪽을 봤다.

- **클래식 진입**(가드 3번이 정면으로 지나가는 길): 모드 선택 → 갈리오 → 시작 →
  "바론한테 간식 10개를 주셨나요?" Alert 이 세로로 뜨고, "예"를 고르니 가로로 전환되며
  **라운드 0/5** 로 드래프트가 떴다. 5라운드가 정확히 반영됐고 가드는 아무것도 막지 않았다.
- **저장**(롤백 2번이 지나가는 길): 5라운드를 완주하니 클래식 레트로 아이템 화면으로 넘어갔고,
  저장하니 상세에 **증강 5개 + 클래식 배지**로 떴다.
- **삭제**: 상세에서 휴지통 → "빌드를 삭제할까요?" → 삭제. 홈 클래식 탭에서 그 빌드가 사라졌다.
- **앱 재시작 후 디스크 대조**: 저장한 칼바람 빌드는 남아 있고 삭제한 클래식 빌드는 없다.
  저장소 원본(`RCTAsyncLocalStorage_V1`)을 직접 열어 확인했다 — `createdAt` 은 UTC 라
  화면의 9/3 이 원본에서는 `2026-09-02T21:…` 로 보인다(KST 오전이라 하루 전). `dayKey` 가
  로컬 기준으로 묶고 표시도 로컬이라 화면은 일관되다. 처음엔 이걸 "저장 누락"으로 오독했다.
- **아레나**(재시도용 `retryCount` state 가 추가된 화면): 라운드 1/12·골드 500·레벨 별
  오버레이가 그대로 뜨고, 픽하니 상점 step 으로 넘어갔다. 회귀 없음.

### 검증하지 못한 것

- **아레나 저장 실패 Alert 자체.** 12라운드를 완주한 상태에서 AsyncStorage 를 실패시켜야
  하는데 시뮬레이터에서 그 조합을 만들 수 없다. 실패 시 `savingRef` 를 풀고 `retryCount` 를
  올려 같은 effect 를 다시 태우는 구조라는 것까지가 코드 수준 보장이다.
- **모달이 닫히는 300ms 레이스.** MCP 탭 한 번의 왕복이 그보다 길어 손으로 만들 수 없다.
  가드가 정상 경로를 막지 않는다는 것만 확인했다.
