## 시작 상태

- 앱에 내장된 10장(`LOCAL_AUGMENT_ICONS`)은 받을 대상이 아니라 캐시에 없는 것이 정상이다.

## 3. 증강·티어리스트

- 실제 드래프트 카드로 나온 것
  - 신규: 더욱 굳건한 태세(골드), 신비한 방호(실버)
  - 재출시: 이빨 요정, 장인의 솜씨
  - 수정한 설명: 붐 앤 베이스(50~175), 자연의 회복(새 동작)
- 티어리스트 출처 문구: "aram.gg 집계 · 패치 26.22 · 2026-11-15 기준". 야스오 상세의 증강 목록(프리즘·골드·실버)도 정상이다

## 4. 회귀 (기존 헤드라이너)

- HEARTSTEEL: 카드 3장 중 2장에 스티커가 붙고(요네·크산테) 1장은 빈다
- 펜타킬: 스킬 카드 3장(헤비·파워·스래시) → 선택 후 증강 카드 3장
- 커맨드 라인: 해킹 리롤 3개
- K/DA: `4 / 4` 뒤 보너스 카드 3장, 카드마다 K/DA 마크

## 미검증

- 가장 낮은 가로 기기(iPhone 16e·SE)에서 4장 배치는 계산으로만 확인했다.
  - 카드 폭은 높이가 정한다: 16e 140pt, SE 135pt.
  - 줄 폭(카드 4장 + 간격 3 + 좌우 패드)은 각각 640pt, 620pt 다. 16e 안전영역 안 폭 약 750pt, SE 667pt 보다 작다.
  - 시뮬레이터 하나를 부팅하는 데 시간이 오래 걸려 실기 캡처는 생략했다.
- 커스텀 모드 그리드에서 삭제된 3종이 빠졌는지는 데이터 검사(`check-augment-data`: 칼바람 233)로만 확인했다.
- 실제 App Store 업데이트 경로(구 바이너리 → 새 바이너리)는 돌리지 않았다. 남아 있던 예전 데이터 위에 새 JS를 올린 것으로 대신했다.

## Findings

- 시뮬레이터 첫 부팅 직후 `simctl install` 이 CoreSimulator 서비스 정지로 몇 분간 멈췄다. 서비스를 재시작하자 풀렸다.
- 앱 테마가 "라이트"로 고정돼 있으면 `simctl ui appearance dark` 가 먹지 않는다. 마이페이지 테마로 바꿔야 한다. 검증 뒤 "라이트"로 되돌렸다.
- 가로 화면에서 뜬 종료 확인창(Alert)은 `ax` 좌표를 회전 변환 없이 그대로 `tap` 해야 한다. 카드·헤더와 다르다.
- 검증 중 저장한 마에스트로 빌드 1개(2026.11.20, 아리)가 시뮬레이터에 남아 있다.
