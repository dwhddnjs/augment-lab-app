# 커스텀 모드 — 아이템 선택 통합 검증

- 날짜: 2026-08-28
- 기기: iPhone 17 Pro 시뮬레이터 (iOS 26.5), Debug 빌드 + Metro
- 대상: 커스텀 화면(`/custom`)에 아이템 선택·빌드 저장 추가

## 사전 확인

- `npx tsc --noEmit` 통과, `npm run lint` 통과.
- 네이티브 변경 없음 — 기존 설치본에 Metro 번들만 갈아끼워 실행.

## 손으로 굴린 결과

| 항목 | 결과 |
|---|---|
| 헤더 토글 탭 → 아이템 | 노브가 검 아이콘 쪽으로 이동, 좌측이 아이템 필터 레일 + 8열 그리드로 교체, placeholder "아이템 이름을 입력해주세요"로 바뀜 |
| 아이템 드래그 → 우측 | 롱프레스 후 끌어 우측 어디에 놓아도 아이템 칸에 담김. 그리드 셀에 accent 테두리 + 체크 배지, 카운트 `1/6` |
| 증강 드래그 → 우측 | 증강 칸에만 담김(아이템 칸으로 새지 않음). 두 목록이 서로 섞이지 않는다 |
| 아이템 검색 | `zz` 입력 시 그리드가 비고 "결과 없음" 표시. 지우면 전체 복귀 |
| 아이템 카테고리 필터 | 필터 탭을 누르면 그 분류만 남고, "전체"로 되돌아온다 |
| 스탯 버튼(챔피언 행) | 모달에 챔피언 아이콘·이름·타이틀·태그 + 스탯 표. 담은 아이템 몫이 `97 (+65)`, `0.938 (+50%)` 처럼 accent 로 붙는다 |
| 드로어 모드 → 클래식 | 아이템 그리드가 레트로 세트로 통째로 교체. 증강 풀도 클래식 것으로 바뀜 |
| 퀵모드 ON | 아이템도 탭 한 번으로 담긴다 |
| 아이템 6개 제한 | 6개를 채운 뒤 7번째를 눌러도 담기지 않고 `6/6` 유지, 셀에 체크가 붙지 않는다 |
| 선택 행 탭 | 담은 아이템 행을 누르면 제거되고 카운트가 줄어든다 |
| 저장(✓) | 세로로 회전하며 빌드 상세가 뜬다 — "클래식" 배지, 증강 2, 아이템 6이 모두 표시 |
| 목록 반영 | 홈 "클래식" 세그먼트 최상단에 방금 만든 빌드가 쌓였다(칼바람 목록에는 없음) |

## 고친 것

- **빈 결과 안내가 안 보였다.** `ListEmptyComponent`의 `flex: 1` 이 contentContainer 높이 0 안에서 죽어 "결과 없음"이 렌더돼도 안 보였다. 증강 그리드에도 있던 문제라 양쪽 `gridContent` 에 `flexGrow: 1` 을 넣어 함께 고쳤다.
- **스탯 모달이 너무 넓었다.** 시트 폭 62% → 42%. 스탯 행이 `space-between` 이라 넓히면 항목명과 값이 양 끝으로 벌어져 읽기 나빴다.

## 확인하지 못한 것

- **드롭 하이라이트의 육안 확인.** 손가락을 뗀 뒤에만 스크린샷을 찍을 수 있어 드래그 중 프레임을 잡지 못했다. 담기는 동작(= `overDrop` 판정)과 종류 구분(= payload `kind`)은 확인했고, 하이라이트는 그 둘을 그대로 읽는 렌더 분기다.
- **드로어 퀵모드 토글은 주입 탭에 반응하지 않았다**(스와이프로는 켜짐). 같은 드로어의 SwiftUI Picker(모드)는 탭으로 잘 바뀌므로 Host 히트테스트 문제는 아니고, simctl 합성 탭과 SwiftUI `Toggle` 의 궁합으로 보인다. 이번 변경과 무관한 기존 컨트롤이다.

## 2차 — UI 정리 (같은 날)

요청 9건(헤더 중앙 배치 · 토글 텍스트화 · 토글 여백 · 섹션 타이틀 축소 · 변경/정보 텍스트 버튼 · 리셋 아이콘 · 아이템 행 아이콘/이름 축소 · 점선 빈 슬롯 · 증강 5개 제한)을 반영하고 같은 기기에서 다시 굴렸다.

| 확인한 것 | 관찰 |
|---|---|
| 헤더 중앙 배치 | 검색(219–517pt) + 토글(524–649pt) 묶음의 중심이 434pt. 안전영역 안쪽(62–812pt) 중심 437pt 과 3pt 차 — 눈으로는 정중앙 |
| 토글 라벨 | 아이콘이 사라지고 "증강 / 아이템". 활성 쪽만 accent, 누를 때마다 반대로 넘어간다 |
| 토글 여백 | 증강일 때 노브 왼쪽 여백 ≈3pt, 아이템일 때 오른쪽 여백 ≈3.7pt(트랙 PAD 4pt). 노브 폭 = 세그먼트 폭이라 양 끝이 같아졌다 |
| 검색 placeholder | 토글을 따라 "증강 이름을…" ↔ "아이템 이름을…" |
| 섹션 타이틀 | "증강 0/5", "아이템 0/6" 이 10pt 로 줄어 카운트와 같은 급으로 붙는다 |
| 변경/정보 버튼 | 글리프 대신 "정보"·"변경" 알약. "정보" 탭 → 스탯 모달이 열리고 아이템 몫이 `50 (+50)`, `21.4 (+11.9)` 로 붙는다 |
| 리셋 아이콘 | 휴지통 → 원형 화살표(`restart`, danger 색). 누르면 증강·아이템이 함께 비고 점선 슬롯으로 돌아온다 |
| 아이템 행 | 아이콘이 증강 타일과 같은 30 틀 안에 23 이미지로 들어가 두 목록의 아이콘 크기가 나란히 같다. 이름은 11pt |
| 빈 상태 | 점선 슬롯 안에 "카드를 넣어주세요" / "아이템을 넣어주세요". 퀵모드 분기 문구는 없앴다 |
| 증강 5개 제한 | 5개를 담은 뒤 6번째("부식")를 끌어다 놓아도 `5/5` 유지, 목록에 추가되지 않는다 |

## 3차 — 코드리뷰 지적 수정 (같은 날)

`/code-review` 로 나온 15건 중 **UI가 바뀌지 않는 11건**을 고치고 같은 기기에서 다시 굴렸다.
(기기: iPhone 17 Pro 시뮬레이터 iOS 26.5, Debug 빌드. 네이티브 변경 없어 Metro 번들만 갈아끼움.
`npx tsc --noEmit` 통과, `npm run lint` 통과.)

| 확인한 것 | 관찰 |
|---|---|
| 빈 상태 저장 가드 | 아무것도 안 담고 ✓ → "저장할 내용이 없어요" Alert. 빌드가 만들어지지 않고 화면도 그대로 |
| 모드 전환 — 남는 것 | 공유 증강 2개(적응형 능력치·육중한 힘, `modes:["aram","classic"]`)를 담고 클래식으로 바꾸니 **2/5 그대로 유지** |
| 모드 전환 — 걸러지는 것 | 같은 상태에서 담아둔 협곡 아이템 2개(헤르메스의 발걸음·마법사의 최후)는 **0/6 으로 빠지고** 점선 슬롯 복귀. 좌측 그리드도 레트로 세트로 교체 |
| 헤더 토글 연타 | 아이템 상태에서 트랙을 두 번 연속 탭 → 아이템으로 제자리. 노브 위치와 좌측 판이 어긋나지 않는다 |
| 증강 드래그 | 롱프레스 후 우측으로 끌어 담김. 카드에 체크 배지, 카운트 1/5 → 2/5 |
| 아이템 드래그 | 같은 조작으로 아이템 칸에 담김(0/6 → 2/6). 증강 칸으로 새지 않는다 |
| 정상 저장 | 증강 2 + 클래식 아이템 1 로 ✓ → 세로 회전 후 빌드 상세. "클래식" 배지, 증강 2·아이템 1·합산 스탯 모두 표시 |
| 나가기(회전 복귀) | `lockOrientation` 래퍼로 바꾼 뒤에도 종료 확인 → 세로 회전 → 홈 복귀가 멈춤 없이 동작 |

### 확인하지 못한 것

- **세로 레이아웃 한 프레임에 화면이 unmount 되던 문제.** `dims` 를 가로일 때만 갱신하도록 고쳤으나,
  재현 조건(회전 잠금 중 세로 레이아웃이 한 번 들어오는 순간)을 시뮬레이터에서 인위적으로 만들지 못했다.
  고친 방향은 "세로 값을 아예 저장하지 않는다"라 이전보다 나빠질 수 있는 경로가 없다.
- **드래그 중 다른 셀을 건드렸을 때의 고스트 유지.** 두 손가락 동시 주입이 필요해 합성 입력으로 만들지 못했다.
  셀마다 `dragging` shared value 를 두어 자기가 시작한 드래그일 때만 취소를 알리도록 했다.
- **토글의 VoiceOver 라벨.** `accessibilityLabel`/`Value`/`State` 를 붙였으나 스크린리더로 듣지는 못했다.
- **드로어를 여는 설정 버튼의 합성 탭이 y좌표 몇 pt 차이에 민감했다**(804 실패 / 795 성공).
  네이티브 SwiftUI glass 버튼의 히트테스트 문제로 보이며 손가락 조작과는 무관하다. 이번 변경과 상관없다.

### 고치지 않고 남긴 것 (UI가 바뀌므로)

- `item-filter-bar` 아이콘 22→20, `arena-shop` 24→20 — 되돌리면 아이템 선택 화면·아레나 상점 UI가 바뀐다.
- `AugmentRarityColors.prismatic.border` `#C6A1FF`→`#E0D6FF` — 되돌리면 다크 모드 `AugmentTile` 전 화면이 바뀐다.
- 아이템 모드에서 정렬 세그먼트가 반응하지 않는 것 — 숨기거나 비활성화하면 드로어 모양이 바뀐다.
