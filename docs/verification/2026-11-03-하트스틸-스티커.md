# HEARTSTEEL 스티커 규칙 + 멤버 얼굴·효과 문구 배치

- **날짜**: 2026-11-03
- **환경**: iPhone 17 Pro (iOS 26.5), 개발 빌드(11-01 빌드 + 이 워크트리 Metro), 다크
- **Verdict**: PASS (라이트 모드·영어는 미확인)

## 바꾼 것

- **스티커 수**: 슬롯마다 40% 확률이던 것을 매 라운드 3장 중 무작위 2장, 서로 다른 멤버로 바꿨다(사용자 플레이 경험).
  `rules.ts` 의 `STICKER_CHANCE`·`rollSticker` 를 `rollRoundStickers` 하나로 바꿨다.
- **리롤**: 스티커는 슬롯에 붙는다. 리롤하면 증강만 바뀌고 그 칸의 멤버는 그대로다.
- **표시**: 카드 우상단 모서리에 멤버 얼굴(34pt 원, 등급색 1pt 테두리, 10° 기울임)을 중심이 꼭짓점에서 대각선으로 8pt 안쪽에 오게 걸치고,
  카드 밑 4pt 에 `멤버: 효과` 한 줄을 두고, 그 밑 8pt 에 리롤 버튼이 온다. 효과는 게임 원문(`full`)이고 10pt, 이름만 굵게.
  효과 줄은 스티커 없는 카드도 같은 높이를 비워 3장의 리롤 버튼 줄을 맞춘다. 높이는 한국어 한 줄(13pt), 영어 두 줄(26pt)이다 —
  한국어 최장(이즈리얼 약 154pt)은 가장 좁은 칸(SE, 카드 135 + 24)에도 한 줄이고, 영어는 요네가 두 줄이라서다.
  옆으로는 카드 사이 간격 절반씩 넘칠 수 있다(폭 = 카드 + 24pt).
  - 거쳐 온 안: 원래는 우상단 흰 테두리 2pt 원형 초상(카드 안쪽) + 카드 밑 2줄 툴팁(초상·이름·줄임말).
    → 초상 + 알약 태그를 카드 윗변 가운데에 걸침 → 초상 없이 카드 위에 문구만 → 문구는 카드 밑, 우상단에 HS 로고
    → 로고 대신 멤버 얼굴(등급색 1pt 테두리, 현재). 테두리를 빼 봤다가 다크 모드에서 카드 밖 원이 배경에 묻혀 되돌렸다.
    모두 사용자 피드백으로 바꿨다.
- **글자색**: 게임 원문(`kiwi_goh_heartsteelaugmentmodifier_*_name_append`)의 색 태그를 따른다. 멤버 이름과 강조어(능력치 모루·크산테 레벨)는
  `keywordMajor` 색 하나로 고정, 스탯 구간만 스탯 색(공격 속도 노랑, 공격력 주황, 주문력 보라, 체력 초록, 흡혈 빨강)이다.
  스킬 가속·`및`·`레벨당` 은 기본 글자색. 문구 JSON 에 `[as]공격 속도 40%[/as]` 처럼 표시하고, 펜타킬 스킬 카드의 표기 렌더를
  `marked-text.tsx` 로 옮겨 함께 쓴다. 픽 현황은 표기를 지우고 평문으로 보인다.
  - 스탯 색은 게임 스탯 아이콘(`texticons/lol/statsicon/scale*.png`) 색, 강조어 색은 인게임 캡처에서 뽑았다. 다크 흡혈만 대비 때문에 밝혔다.
    라이트는 같은 색상에서 명도만 내려 배경 대비 4.5:1 을 맞췄다(`StatTextColors`).
- 카드 밑 줄은 4 + 13 + 8 = 25pt 로, 이전 툴팁(2 + 28 + 4 = 34pt)보다 낮아 같은 화면 예산 안이다.

## Steps

| 대상 | 드라이브 | 결과 |
|---|---|---|
| 첫 라운드 | 앱 재시작 후 `augmentlab://aram?championId=Ahri&headliner=heartsteel` | 1·2번 카드 우상단 둥근 모서리 안에 요네·이즈리얼 얼굴, 카드 밑에 `요네: 공격 속도 40% 및 스킬 가속 20`, `이즈리얼: 레벨당 공격력 4 및 주문력 4`. 3번은 둘 다 없고 리롤 버튼 높이는 3장 같음. 카드·문구 4pt, 문구·리롤 8pt |
| 리롤 유지 | 스티커 칸·빈 칸 리롤(태그 버전에서 확인, 로직 같음) | 스티커 칸은 증강만 바뀌고 멤버 그대로(`폴터가이스트 → 순수주의자 - 마법사`, 이즈리얼 유지). 빈 칸은 계속 빈 칸 |
| 여러 라운드 | 가운데 카드 선택을 이어 감 | 매 라운드 정확히 2장, 빈 칸 위치가 라운드마다 다르고 한 라운드 안에 같은 멤버 없음 |
| 가장 긴 문구 | 요네·이즈리얼 (첫 라운드 실버) | 둘 다 카드 밑 한 줄로 다 보이고 옆 카드 문구와 닿지 않음 |
| 글자색 | 4라운드 진행하며 문구만 잘라 비교(카드 위에 둘 때 확인, 색 처리는 같음) | 이즈리얼 `공격력 4` 주황·`주문력 4` 보라, 세트 `체력 30` 초록, 케인 흡혈 빨강, 요네 `공격 속도 40%` 노랑, 크산테 레벨은 이름과 같은 색. 대괄호 표기가 글자로 새지 않음 |
| 규칙 검사 | `npx tsx scripts/check-headliners.ts` (20만 회) | 매번 2장·멤버 중복 없음·빈 칸 위치 1/3 ±1%, 두 언어 색 표기 짝 통과 |

미확인:
- 라이트 모드 글자색. 기본 글자는 테마색, 스탯·이름은 `StatTextColors.light` 로 바뀐다(계산상 4.5:1 이상).
- 영어. 글자 폭 계산으로는 `Yone: 40% Attack Speed and 20 Ability Haste` 만 두 줄(229pt / 168pt)이고 나머지는 한 줄이다.
  영어는 효과 줄을 두 줄 높이로 잡아 리롤 버튼과 겹치지 않는다.
