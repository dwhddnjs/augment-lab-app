# 드래프트 종료 → 빌드 상세 전환 (프로덕션 UI 블록)

- 일시: 2026-09-04
- 기기: iPhone 17 Pro 시뮬레이터 (iOS 26.5), dev 빌드 / Metro
- 대상 변경: `dismissTo("/") + push("/build/[id]")` → `replace("/build/[id]")` (아레나·칼바람·커스텀 3곳)

## 증상 (프로덕션에서만 재현)

아레나 12라운드 완료 후 빌드 상세로 넘어갈 때 깨진 화면이 뜨고, 헤더 뒤로가기를 눌러야 정상 화면이
나타난다. 시뮬레이터(dev)에서는 재현되지 않았다.

## 원인

expo-router 56은 라우팅 액션을 즉시 dispatch 하지 않고 `routingQueue` 에 모았다가
`useSyncExternalStore` → `useEffect` 에서 한 번에 flush 한다
(`node_modules/expo-router/build/global-state/routingQueue.js`). flush 루프는 각 액션마다
`navigationRef.getRootState()` 를 새로 읽어 대상 navigator 를 계산하는데, 바로 앞 dispatch 는
React Navigation 의 reducer 특성상 아직 state 에 반영되어 있지 않다.

그래서 `dismissTo` 와 `push` 를 잇달아 부르면 **화면 제거와 추가가 한 프레임에 겹친다.** 여기에
`PORTRAIT_UP` 세로 복귀 회전까지 동시에 걸리면서 UIKit 이 전환을 마무리하지 못하고 죽은 프레임이
남았다. 릴리즈 빌드는 JS 가 빨라 두 호출이 확실히 같은 배치에 들어가고, dev 빌드는 느려 서로 다른
렌더 배치로 갈리는 일이 잦아 우연히 정상 동작했다 — 프로덕션에서만 보인 이유다.

드래프트 진입은 전부 `replace` 체인(`mode-select` → `select-champion-modal` → 드래프트 화면)이라
스택은 항상 `[(tabs), 드래프트화면]`. `replace` 한 번이면 최종 스택이 같고 전환도 1회다.

## 굴려본 것

### 아레나 12라운드 (문제의 경로)

갈리오… 가렌으로 새 판을 시작해 12라운드 step 을 전부 통과했다
(R1 증강 → R1 상점 → R2 프리즘 → R3 증강 → R4 상점 → R5 증강 → R6 상점 → R7 증강 →
R8 재련 → R9 상점 → R10 증강 → R11 상점 → R12 증강).

- R12 마지막 카드를 고른 직후 **빌드 상세가 곧바로 정상 렌더**됐다. 세로 복귀 완료, 챔피언 배너·
  증강 4장·헤더(뒤로가기/삭제) 모두 제자리. 깨진 프레임 없음.
- 헤더 뒤로가기 1회 → 홈("내 빌드")으로 복귀. **아레나 화면이 스택에 남아 있지 않다** —
  `dismissTo + push` 였을 때와 스택 구성이 동일함을 확인.
- 아레나 탭에 방금 판(가렌, 2026.9.4)이 증강 4 + 프리즘 1 로 최상단 저장됐다.

### 칼바람 (같은 코드 경로, `use-item-select`)

갈리오로 4라운드 픽 → 아이템 선택 화면(`replace` 로 진입) → 아이템 1개 선택 후 저장.

- 빌드 상세가 정상 렌더(증강 4 + 아이템 1), 세로 복귀 정상.
- 헤더 뒤로가기 1회 → 홈 복귀. 아이템 선택 화면이 스택에 남지 않음.

커스텀(`use-custom-draft`)은 바뀐 줄이 위 둘과 동일해 굴리지 않았다.

## 한계

이 버그 자체는 릴리즈 빌드에서만 재현되므로 **시뮬레이터 dev 빌드에서 "고쳐졌다"를 직접 관찰한 것은
아니다.** 여기서 확인한 것은 회귀가 없다는 것 — 전환·스택·저장이 모두 이전과 동일하게 동작한다.
실제 수정 확인은 다음 프로덕션 배포에서 아레나 12라운드를 한 번 돌려봐야 한다.
