# 데이터 관리 화면 UI 개편 — 시뮬레이터 검증

- **날짜**: 2026-08-21
- **Verdict**: ✅ **PASS**
- **환경**: iPhone 17 Pro (**iOS 26.5**), dev-client debug 빌드 (`xcodebuild` + 시뮬레이터 MCP `launch`, Metro :8081)

한 덩어리였던 데이터 관리 리스트를 **백업·복원 / 초기화** 두 섹션으로 나누고, 각 행에
설명 한 줄을 붙였다. 라벨에서 중복되던 "데이터"를 걷어내고, 헤더 뒤로가기의
"마이페이지" 라벨도 없앴다.

## 검증 대상

| 파일 | 변경 |
| --- | --- |
| `app/(tabs)/(mypage)/_layout.tsx` | `data` 화면에 `headerBackButtonDisplayMode: 'minimal'` |
| `features/mypage/components/settings-row.tsx` | `description` 슬롯 추가 — `VStack`(라벨 + footnote 2줄 행) |
| `features/mypage/screens/data-manage-screen.tsx` | 섹션 2개로 분리, 라벨 `백업`/`복원`/`초기화`, 행별 설명, 백업 우선 순서, 백업·복원 아이콘을 accent 색으로 |

## Findings

1. **아레나 탭이 비어 보이는 건 복원 누락이 아니다.** 초기화 전 상태를 안 보고 넘어가
   판정이 애매했는데, 백업 파일을 직접 열어 보니 빌드 9개가 **전부 `mode=aram`** 이었다.
   아레나 빌드는 원래 0개. 화면만 보고 "복원이 빠졌다"고 적을 뻔했다 —
   불확실하면 컨테이너의 원본 JSON을 열어 대조하는 편이 빠르다.
   (`xcrun simctl get_app_container <udid> com.augmentlab data` →
   `Library/Application Support/com.augmentlab/RCTAsyncLocalStorage_V1/`.
   큰 값은 manifest.json에 `null`로 남고 옆 해시 파일에 실제 문자열이 들어 있다.)
2. **행 우측의 chevron(`>`)이 어포던스와 어긋난다.** 세 행 모두 화면 이동이 아니라
   시트/Alert를 띄우는 액션인데 disclosure indicator가 붙어 있다. 이번 범위 밖이라
   그대로 뒀다 — 떼는 편이 iOS HIG에 맞다.
3. **"초기화" 섹션 타이틀과 행 라벨이 같은 단어다.** 섹션에 행이 하나뿐이라 반복이 눈에 띈다.
   구분감을 위해 섹션은 유지했지만, 타이틀을 지우고 footer만 남기는 선택지도 있다.
4. 검증 절차를 `cliclick` + 베젤 좌표 계산에서 **시뮬레이터 MCP**로 갈아탔다. 좌표가
   device point로 바로 들어가 배율·오프셋 계산이 통째로 사라졌다.
   `.agents/skills/verify/SKILL.md` 를 그 기준으로 다시 썼다.

## 빌드 메모

`npx expo run:ios` 가 **CocoaPods 단계에서 10분간 멈춰 있었다**(자식 프로세스 없음).
원인 두 가지:

- `LANG` 미설정 → CocoaPods가 `Encoding::CompatibilityError`로 즉사.
  `export LANG=en_US.UTF-8` 이 필요하다.
- Pods는 이미 설치돼 있고 `Podfile.lock` == `Pods/Manifest.lock` 이었으므로
  pod install 자체가 불필요했다. `xcodebuild` 를 직접 돌려 **166초**에 끝났다.
