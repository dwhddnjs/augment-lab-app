# 칼바람 기준 증강 교정(비공개 3건 · 설명·아이콘 9건) — 시뮬레이터 검증

- **날짜**: 2026-08-20
- **Verdict**: ✅ **PASS**
- **환경**: iPhone 17 Pro (iOS 26.5), Expo dev client + Metro(:8092), 다크 모드, 한국어

## 배경

증강 풀(`augment-lists.json`의 `KIWI`)에 들어 있어도 **실제 칼바람 드래프트에는 뜨지 않는** 증강이
있다. 데이터만 보고는 알 수 없고 게임에서 확인해야 한다. 여기에 더해 설명·아이콘이 다른 증강 것과
섞이거나 수치가 뒤집힌 건들을 인게임 화면 기준으로 바로잡았다.

## 비공개 처리 — 칼바람 드래프트에서 제외

`modes`에서 `aram`을 뺐다. 데이터는 남으므로 과거 빌드 조회에는 영향이 없다.

| 증강 | 근거 |
| --- | --- |
| 2연속 방어 | 위키도 "데이터에는 있으나 비활성으로 보인다"고 적고 있다 |
| 서포터 주력 | 위키 증강 목록에 아예 없다 |
| 신발 수집가 | 위키 증강 목록에 아예 없다 |

`tag-augment-modes.mjs`를 다시 돌려도 되살아나지 않게 스크립트에 `NOT_IN_ARAM` 목록으로 박고,
`check-augment-data.mjs`에 회귀 검사를 넣었다. 칼바람 220 → **217개**.

줄어드는 map30 값은 아레나 기준이거나 구버전으로 보고 **위키 값(250/150)을 택했다.**

## 아이콘 교정 — 그리고 자동 교정을 아예 껐다

| 증강 | 전 | 후 |
| --- | --- | --- |
| 꽁! | `Bonk_large.png` | 공허 돌진과 동일한 `GenericAbilityAugmentIcon_Gold.png` |
| 바늘꽂이 | `SymphonyOfWar_small.png` | 메아리 시전과 동일한 `GenericAbilityAugmentIcon_Prismatic.png` |

앞선 작업에서 `tag-augment-modes.mjs`가 아이콘을 "CDragon 기준으로 교정"했는데, **CDragon 값이
실제 인게임 아이콘과 다른 경우가 있어** 손으로 맞춰둔 아이콘을 도로 망가뜨렸다(BONK!는 게임에서
generic을 쓰는데 CDragon은 `bonk_large.png`를 준다).

→ **스크립트의 아이콘 쓰기를 제거했다.** 이제 CDragon과 다른 건만 리포트하고 판단은 사람이 한다.
현재 차이 5건(빵 3종 · 꽁! · 바늘꽂이)은 전부 앱 값이 맞다.

## EN 설명 잔재 정리

영문 설명에 위키·게임 원문 찌꺼기가 7건 남아 있어 함께 정리했다 —
`This augment is currently disabled.`(흡혈병·공허 돌진), `Damage calculated after modifiers`(흡수),
`counts up to 1 hit per champion per cast instance`(가속 추구·위력 추구), 깨진 문장(유리 대포·무리한 진입).

## Findings

- **PASS — 지시한 9건 + 조준경 3종 전부 반영.** 화면에서 직접 확인했다.
- **PASS — 비공개 3건이 칼바람 풀에서 빠졌다.** 스크립트를 다시 돌려도 유지된다.
- **PASS — 아이콘이 스크립트에 의해 다시 덮이지 않는다.**
- `npx tsc --noEmit`, `npm run lint` 통과.

## 남은 것

- 위키가 "현재 비활성"이라 적은 증강이 아직 7건 더 칼바람 풀에 있다 —
  단호함 · 인내 · 눈덩이 업그레이드 · 흡혈병 · 양자 연산 · 어깨 위의 악마 · 최후의 도시 대중교통.
  위키 표기만으로는 근거가 약해 그대로 두었다. 게임에서 확인되면 `tag-augment-modes.mjs`의
  `NOT_IN_ARAM`에 `augmentNameId`를 추가하면 된다.
- 검수 페이지(`docs/augment-check.html`)의 `미출시만` 필터로 현재 제외된 38건을 볼 수 있다.
