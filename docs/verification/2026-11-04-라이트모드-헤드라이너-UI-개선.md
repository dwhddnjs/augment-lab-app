# 라이트 모드 헤드라이너 UI 개선 7건 — 검증

- 날짜: 2026-11-04
- 기기: iPhone 17 Pro (iOS 26.5) 시뮬레이터, 라이트 모드, 가로
- Verdict: **PASS** (다크 모드 육안 확인은 SKIP — 아래 Findings)

## Steps

1. `augmentlab://aram?championId=Ezreal&mode=aram&headliner=command-line` → 헤더 로고·리롤 아이콘 색·크기 확인
2. 3라운드 선택 → 픽 현황 Drawer 열어 헤드라이너 박스·증강 칸 확인
3. 4라운드까지 선택 → 아이템 화면 우측 패널 스크롤, 헤드라이너 박스·증강 타일 확인
4. `...&headliner=heartsteel` → 스티커 얼굴 위치·카드 밑 스탯 문구 그림자 확인, Drawer 헤드라이너 박스 확인

| # | 항목 | 전 | 후 |

| 1 | Drawer 헤드라이너 박스 | 여백 16·간격 16·아이콘 40 | 여백 12·간격 12·아이콘 32. 박스 높이가 눈에 띄게 줄었다 |

## 2차 — 전환 증강 효과 + Drawer 6칸 (같은 날)

- Verdict: **PASS**
- 전환 증강을 1~4라운드에 강제로 띄우는 임시 패치로 굴리고 되돌렸다(카드 3장에 전환 증강을 앞세움).

### Steps

1. `...&headliner=disco` → 1라운드 전환: 골드, 2라운드 전환: 혼돈, 3라운드 전환: 프리즘 선택 → Drawer 확인
2. 4라운드 판도라의 상자 선택 → 아이템 화면 증강 확인

### Findings

- 전환 증강 자신은 Drawer 에 쌓이지 않는다. Drawer 증강 4/6: 전환: 지형 생성됨(골드) · 전환: 자연의 회복(골드) · 전환: 광대 대학(프리즘) · 전환: 튕기는 꿀벌(프리즘)
- 판도라의 상자: 기존 4개가 모두 빠지고 프리즘 4개(전환: 해악의 숫자 3 · 전환: 양손잡이 · 전환: 이케시아의 몰락 · 전환: 대마법사)로 바뀌었다. 판도라 자신은 빠진다
- Drawer 칸 6개(3×2), 박스 크기 그대로 아이콘이 커졌다(0.66 → 0.78)
- 저장된 빌드 상세·목록은 id 로 이름을 다시 찾아 "전환:" 접두어가 붙지 않는다(이번 범위 밖)

  - 네 모서리 확대에서도 틈·선 없이 그림자가 붙는다
