# 홈 리디자인 — 런처형 홈 + 내 빌드 컬렉션 + 커스텀 배지

- 날짜: 2026-11-20
- 기기: iPhone 17 Pro 시뮬레이터 (iOS 26.5), Metro 개발 빌드
- Verdict: **PASS**

## 바뀐 것

- 홈(`(home)/index`) = 칼바람 시작 카드(26.23 신규 헤드라이너 4종 + 무대 조명) → 최근 빌드 캐러셀(8개) → 지금 S티어 5명.
- "전체 보기" → 새 화면 `(home)/builds` "내 빌드": 2열 그리드 + 네이티브 세그먼트(전체·최근 7일·프리즘·커스텀).
- 빌드 카드: centered splash(1280×720) 세로 카드. 왼쪽 위 배지 = 헤드라이너 로고, 커스텀 빌드는 커스텀 아이콘(+ 메뉴의 커스텀과 같은 `tune-variant`).
  헤드라이너 색(커스텀은 민트)은 테두리·그림자에만 쓴다.
- 저장: `SavedBuild.custom?: true` 추가, 커스텀 화면 저장 시 붙는다.

## Steps

1. 앱 재실행 → 홈. large title "증강 연구소", 시작 카드 로고 4종 + 이름(헤드라이너 색), "칼바람 시작" 버튼(눈송이) 확인.
2. 최근 빌드 캐러셀: 세 번째 카드가 화면 끝에 걸침. 증강 5개 이상인 카드는 4칸 + "+2" 칸으로 줄어듦.
3. 지금 S티어: tierlist.json S티어 앞 5명(야스오·트위스티드 페이트·요네·마스터 이·탐 켄치) 표시.
4. + → 커스텀 → 가렌 → 퀵모드로 증강 2개 → 저장 → 빌드 상세 → 뒤로.
   홈 캐러셀 첫 카드가 가렌, 왼쪽 위 민트 커스텀 아이콘, 민트 테두리·그림자.
5. 전체 보기 → "내 빌드" 화면 push(뒤로 버튼 "증강 연구소"). 세그먼트가 화면 폭을 채움.
6. 세그먼트 "커스텀" → 가렌 1장만, 반 폭 유지(홀수 개여도 늘어나지 않음). 빌드 0개 필터에선 "조건에 맞는 빌드가 없어요".
7. 앱 테마 다크로 바꿔 홈·내 빌드 확인 → 라이트로 되돌림.

## Findings

- **카드 그림이 흐리고 가려짐(수정함)**: 처음엔 로딩 아트(308×560)를 써서 카드 폭(3x 약 520px)에서 1.7배 늘어나 흐렸고,
  헤드라이너 색 워시 + scrim 이 화면 중간(30%)부터 깔려 얼굴을 덮었다. centered splash 로 바꾸고 워시를 빼고
  scrim 을 아래 48%(52%→100%)에만 깔았다. 칭호 줄은 글자 그림자로 보강. 3x 캡처에서 얼굴 선명, 위쪽 절반 원본 그대로.
- **카드 아래 그림자 과함(수정함)**: `0 14 28 -16` 55% → `0 6 14 -8` 30%. 3x 캡처, 가렌 카드 가로 중앙에서 아랫변 아래
  세로 프로파일(배경 R=242): 바로 아래 184→214, 36px 아래 221→240(배경과 거의 같음). 그림자 꼬리가 약 10pt 안에서 끝난다.
- theme.ts 를 고치면 Fast Refresh 가 전체 리로드로 떨어져 몇 초간 검은 화면이 남았다. 앱 재실행으로 정상 — 코드 문제 아님.
- 이 필드 도입 전 커스텀 빌드는 `custom` 표시가 없어 배지 없이(헤드라이너 없는 칼바람과 같게) 나온다.
- (home) 스택은 가로 화면을 다녀오면 `navKey` 로 통째로 재생성된다(기존 우회). 내 빌드 화면에서 + 로 드래프트를 다녀오면 홈으로 돌아온다.

## 3차 — 배지 원형 (같은 날)

- Verdict: **PASS**
- 커스텀 배지가 26×34 타원이었다(좌우 여백 8pt). 배지 좌우 여백을 (26−18)/2 = 4pt 로 바꿔 정사각 아이콘·로고는 26×26 원,
  가로로 긴 로고(K/DA)만 캡슐로 늘어난다. 날짜 캡슐은 그대로.
- 3x 캡처 확대: 가렌 카드 배지 원판 가로·세로 모두 약 78px(26pt) — 원형.

## 4차 — 배지 로고 축소 + 날짜 캡슐 축소 (같은 날)

- Verdict: **PASS**
- 원판·로고 중심은 이미 1px 안으로 맞았다(3x, 원판 현 위 가장자리 기준 가렌 110/111·마에스트로 590/590·worlds 1070/1070.5).
  치우쳐 보인 건 18pt 로고가 26pt 원을 거의 채워 테두리에 닿아서였다 → 헤드라이너 로고만 15pt. 커스텀 아이콘은 글리프 여백이 있어 18pt 유지.
- 3x 캡처 worlds 로고 bbox 1050–1092 × 1412–1452, 원판(중심 1070/1432, 반지름 39px) 안 여백 좌 19·우 17·위 19·아래 19px.
- 날짜 캡슐: 높이 26pt 그대로(배지와 윗선 맞춤), 글자 12→11pt·좌우 여백 8→6pt. 원 배지 옆에서 덩치가 비슷해졌다.

## 5차 — 시작 카드를 "헤드라이너 골라 시작"으로 (같은 날)

- Verdict: **PASS**
- 문제: 신규 헤드라이너 4종 로고는 설명도 없고 누를 수도 없어 장식에 그쳤다(드래프트 헤드라이너는 무작위라 홈에서 본 걸로 시작할 방법이 없었다).
- 변경:
  - 시작 카드 = 헤드라이너 13종 가로 타일(새 4종 앞 + NEW) + "랜덤 헤드라이너로 시작" 버튼.
  - 타일을 누르면 챔피언 선택 → 드래프트까지 `headliner` 파라미터가 넘어가 그 헤드라이너로 고정된다.
    `aram-screen` 의 헤드라이너 고정은 `__DEV__` 전용이던 것을 정식으로 열었다. `+` 메뉴·랜덤 버튼은 지금처럼 무작위.
  - `NEW_HEADLINERS {patch, ids}` → `NEW_HEADLINER_IDS` (카드에 패치 번호 문구를 더 쓰지 않는다).
- Steps:
  1. 홈 시작 카드: 아케이드·연미복·망자의 환영(NEW) + 마에스트로가 끝에 걸침. 왼쪽으로 넘기면 K/DA…열혈 팬까지 13종.
  2. 연미복 타일 → 가렌 → ✓ → 드래프트 상단 헤드라이너 로고가 연미복. 종료.
  3. 랜덤 버튼 → 갈리오 → ✓ → 열혈 팬(라운드 0/5)이 무작위로 걸림. 종료 → 홈 복귀.
- Findings:
  - 타일 이름에 `adjustsFontSizeToFit`(+`minimumFontScale 0.85`)를 걸자 Fabric 에서 최소 배율을 무시하고 6pt 안팎까지 줄었다.
    자동 축소를 빼고 타일 폭을 96pt 로 넓혀 가장 긴 이름(HEARTSTEEL·귀염둥이 카페)도 caption 12pt 그대로 들어가게 했다.
  - 드래프트 종료 Alert 는 이번엔 ax 좌표 그대로 탭하면 안 먹고 회전 변환((1−y), x)해야 눌렸다.
