# 증강 카드 게임 프레임 + 희귀도 색 토큰 교체

- **날짜**: 2026-11-03
- **환경**: iPhone 17 Pro (iOS 26.5), 개발 빌드(11-01 빌드 재설치 + 이 워크트리 Metro)
- **Verdict**: PASS (K/DA 보너스 카드 글로우는 미확인)

## 바꾼 것

- 증강 카드(`RarityCardFrame`)를 CSS 그라데이션 테두리에서 게임 원본으로 바꿨다. 원본은 CDragon
  `game/assets/ux/cherry/augments/augmentselection/augmentcard_bg.png`, `augmentcard_frame_{silver,gold,prismatic}.png`
  이고, 512 캔버스에서 카드 영역(x 100~413, 313×512)만 잘라 `assets/augment-card/` 에 넣었다.
  펜타킬 스킬 카드가 쓰던 `skill-card-{bg,frame}.png` 는 위 원본을 x 101~412 로 자른 것과 픽셀 단위로
  같아서 지우고, 증강 카드와 같은 파일을 쓴다.
- 같은 폴더의 `_classic_v2`(아수라장 클래식), `goh` 변형과 `kiwi/.../augmenticon_defaultbacklayer_*`(소용돌이
  문양)도 받아 봤다. 칼바람 카드는 기본 프레임이 맞다. 소용돌이 문양은 깔지 않는다. 아수라장 `_large` 아이콘에
  문양이 이미 그려져 있어서, 깔면 두 겹이 된다.
- `AugmentRarityColors`·`AugmentRarityColorsLight` 를 프레임 테두리 그라데이션에서 뽑은 색으로 바꿨다.
  다크는 금속 면의 색이고, 라이트는 같은 그라데이션에서 흰 배경 대비 3.5:1 을 처음 넘는 지점의 색이다.

  | | 다크 (이전 → 이후) | 라이트 (이전 → 이후, 흰 배경 대비) |
  |---|---|---|
  | 실버 | `#9BA3AE` → `#B5B6B5` | `#828A93` → `#848484` (3.7:1) |
  | 골드 | `#E8B339` → `#D0AE80` | `#AD821F` → `#9C7A58` (3.9:1) |
  | 프리즘 | `#E0D6FF` → `#B592D6` | `#9877DA` → `#976ED3` (3.8:1) |

- 티어리스트 S 는 따로 두던 `#D3BFFF` 대신 프리즘 토큰을 쓴다. 예전 프리즘은 넓은 배너에서 색이 날아갔지만, 새 보라는 그렇지 않다.
- 커맨드 라인 마크는 라이트 모드에서 골드 토큰을 빌려 칠했다. 토큰이 샴페인색으로 바뀌어도 모양이 그대로 나오도록
  `CommandLineLightTint` 로 떼어 내고 값(`#AD821F`/`#E8B339`)은 유지했다.
- 픽 현황 Drawer 의 증강 칸 테두리·이름, 아이템 화면 증강 이름에 희귀도 색을 입혔다. 둘 다 회색이었다.

## Steps

| 대상 | 드라이브 | 결과 |
|---|---|---|
| 드래프트 골드 | `augmentlab://aram?championId=Ahri&headliner=true-damage`, 라이트 | 게임 골드 프레임·청록 배경. 아이콘·이름·설명 프레임 안. 처음엔 꽉 찬 설명 줄이 양옆 장식선에 닿아 설명에 좌우 4pt 여백을 더했고, 이후 닿지 않음 |
| 드래프트 프리즘 | 라운드 2·3 진행 | 무지개 프레임, 아이콘 홀로그램과 어울림. 5줄 설명도 프레임 안 |
| 커스텀 그리드(compact) | `augmentlab://custom?championId=Ahri`, 전체·프리즘·골드 필터 | 실버·골드·프리즘 프레임 모두 작은 카드에서도 깨짐 없음. 레일 활성 색이 카드 프레임 색과 같음 |
| 펜타킬 스킬 카드 | `headliner=pentakill` | 공용 배경·골드 프레임으로 이전과 같은 모습 |
| 다크 모드 드래프트 | 마이페이지 테마 → 다크, `headliner=kda` | 골드 글로우가 어두운 배경에서 보임. `500골드` 강조가 골드 토큰 색 |
| 픽 현황 Drawer | 2장 고른 뒤 열기, 다크 | 골드 칸 샴페인 테두리·이름, 프리즘 칸 보라 테두리·이름 |
| 티어리스트 | 티어리스트 탭, 다크 | S 배너가 보라로 읽힘, 챔피언 타일 테두리 보라 |
| 아이템 화면 | 4라운드 완료 후 아이템 선택, 라이트 | 증강 이름 실버 회색 / 프리즘 보라 / 골드 브론즈, 흰 배경에서 읽힘 |

## Findings

- 카드 비율은 앱의 14:9 를 유지했다. 게임 원본(313×512)은 세로로 약 5% 눌리지만 눈으로는 구분되지 않는다.
- 미확인: K/DA 보너스 카드(`variant="kda"`)의 파란 글로우. 코드는 바뀌지 않았고 4라운드를 끝까지 가야 볼 수 있다.
- 시뮬레이터의 앱 테마는 확인 뒤 라이트로 되돌렸다.

## 2차 — 인게임 배치 비율 + 읽히는 글자 크기 (같은 날)

실제 칼바람 증강 카드 화면 3장(실버 `빙글빙글`, 골드 `밤의 추적`, 프리즘 `어깨 위의 악마`)을 재서 카드 안 배치를 옮겼다.
게임 카드는 원본 프레임 비율(1:1.64)이고, 세 장의 위치가 1% 안에서 같다(내용과 무관한 고정 배치).

| 요소 | 인게임 측정 | 앱 적용 |
|---|---|---|
| 아이콘 | 원본 아이콘을 화면에 겹쳐 맞춤: 캔버스 0.50W, 중심 0.227H (두 장 오차 0.004) | 그대로. 드래프트 72pt |
| 이름 | 글자 윗선 0.459H | 그대로(줄 상자 보정 0.18em 을 시뮬레이터에서 재서 맞춤, 오차 1px) |
| 이름 ↔ 설명 | 사이에 분류 태그(일반·보조) 0.515~0.545H | 앱 데이터에 분류가 없어 설명을 이름 바로 밑(드래프트 8pt, 그리드 4pt)에 붙임 |
| 글자 크기 | 이름 0.073W, 설명 0.046W | **따르지 않음.** 그대로면 설명 6.6pt 라 읽히지 않는다는 피드백. 드래프트 이름 12 / 설명 9 (줄 12.5), 커스텀 그리드 이름 10 / 설명 7.5 (줄 10.5) |
| 좌우 여백 | 0.12W | 0.14W. 0.10W 는 글자가 프레임에 붙어 보인다는 피드백 |

- 설명 줄 간격은 글자의 1.4배다. 처음 1.2배(9/11, 8/9.5)는 줄이 붙어 보인다는 피드백으로 넓혔다. 그리드는 카드가 좁아 8pt 로는
  1.4배 간격에 가장 긴 설명이 들어가지 않아(여백을 줄여도 1장 넘침) 7.5pt 로 내렸다.
- 모든 카드가 같은 글자 크기를 쓴다. 긴 설명만 줄이는 `adjustsFontSizeToFit` 는 한 번 넣었다가 뺐다(카드마다 크기가 달라짐).
- 이름은 `lineBreakStrategyIOS="hangul-word"` 로 단어 단위로 끊는다(`무한의 대검 업그레이 / 드` → `무한의 대검 / 업그레이드`).
  설명은 글자 단위 그대로다 — 단어 단위면 그리드에서 3장(`핏빛 코발트`·`죽음의 춤`·`구원`)이 같은 크기로 들어가지 않는다.
- 줄 수 계산은 iOS 실제 줄바꿈보다 한 줄 적게 나와서(`떴다, 징크스` 실측 7줄), 폭의 97% 로 보수적으로 잡아 전 증강을 검사했다.

| 대상 | 드라이브 | 결과 |
|---|---|---|
| 인게임과 나란히 | 드래프트 캡처를 게임 카드와 같은 폭으로 나란히 | 아이콘 크기·위치, 이름 위치 일치 |
| 가장 긴 설명 | 커스텀 검색(클립보드 붙여넣기) `징크스`, `황홀한`, `죽음의 무도` | 그리드 7.5pt·줄 10.5 로 모두 표시, 잘림 없음 |
| 두 줄 이름 | 커스텀 검색 `업그레이드` 11장 | 단어 단위로 두 줄, 설명까지 잘림 없음 |
| 드래프트 | `headliner=true-damage` | 9pt 설명·줄 12.5, 좌우 20pt 여백. 두 줄 이름(`꽃피는 새벽의 검 업그레이드`)도 잘림 없음 |

| 드래프트 긴 설명 | `headliner=heartsteel` (앱 재시작 후 링크) | `떴다, 징크스` 가 9pt 6줄로 다 보임. 아래 장식선과 한 줄 넘게 떨어짐 |
| 헤더 로고 | 8종 헤드라이너 | 로고 28pt 로 줄여 라운드 pill 보다 가벼움. K/DA 마크는 40pt 유지, 꿀벌은 둥근 이모트라 28pt 면 작아 보여 34pt |

드래프트에서 가장 긴 설명은 보수적 계산으로 최악 95.3pt / 가용 100.9pt 다. 화면에서는 `떴다, 징크스` 까지 확인했다.
헤드라이너 고정 링크는 드래프트가 처음 뜰 때만 먹는다. 이미 드래프트가 떠 있으면 앱을 다시 띄운 뒤 보내야 한다.
