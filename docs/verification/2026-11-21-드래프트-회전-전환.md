# 드래프트 가로 전환을 iOS 회전에 맡기기 (검은 빈 화면 제거)

- 날짜: 2026-11-21
- 기기: iPhone 17 Pro 시뮬레이터 (iOS 26.5, `5FC3FF75-7D05-47F7-ABD9-E042378149AB`). Debug 빌드와 Metro를 썼다.
- **Verdict: PASS** (나가기의 "가로 홈 → 회전"은 남는다 — 아래 Findings)

## 바꾼 것

- 드래프트(칼바람·아이템 선택·커스텀)를 `presentation: 'fullScreenModal'` + `orientation: 'landscape'` 로 띄운다. 회전은 iOS 가 전환과 함께 한다.
  예전에는 코드로 회전을 걸고(`useLandscapeLock`·`lockPortrait`) 도는 동안 빈 화면으로 가렸다.
- 챔피언 시트 위에 드래프트를 쌓고(push), 칼바람 → 아이템도 쌓는다. 갈아 끼우면(replace) 앞 모달을 닫는 순간 세로로 돌았다 다시 돈다.
- 닫기는 `useCloseDraft` 하나로 한다. 저장은 시트를 애니메이션 없이 닫고 빌드 상세를 모달 아래에 미리 깐다. 나가기는 페이드로 닫는다.
- 앱 기본 방향은 루트에서 `PORTRAIT_UP` 으로 잠근다. 드래프트가 아닌 화면에는 orientation 옵션을 주지 않는다(아래 Findings).
- 마지막 라운드 픽은 카드를 다시 돌리지 않고 고른 모습 그대로 멈춘 채 아이템 화면으로 넘어간다.
- 드래프트 안의 `SafeAreaView` 를 `InsetView`(useSafeAreaInsets 기반)로 바꿨다.

## 확인 방법

`simctl io recordVideo` 로 녹화한 영상을 60fps 로 쪼갠 뒤 프레임 밝기로 빈 구간을 쟀다. 화면 모습은 프레임 시트로 봤다.
회전 도중 녹화기는 프레임 방향을 바꿔 기록해서 중간 모습이 실제와 다를 수 있다. 그래서 저장 경로는 `simctl io screenshot` 연속 촬영(장당 약 0.5초)으로 실제 화면을 한 번 더 봤다.

## Steps · 관찰

| 칼바람 4+1 라운드 → 아이템 선택 | 나머지 카드가 사라지고 고른 카드만 남은 채 아이템 화면이 페이드로 덮는다. 카드가 다시 돌지 않는다(수정 전에는 다음 라운드처럼 한 번 더 돌았다) |

| 칼바람 픽 현황 서랍 | 정상 |

## Findings

- **드래프트가 아닌 화면에 orientation 을 주면 홈이 가로로 돈다.** 루트 스택에 `orientation: 'portrait_up'` 을 주었더니 빌드 상세에서 뒤로 오면 홈이 가로가 됐고, 저장 때 세로 → 가로 → 세로로 흔들렸다.
  옵션이 하나라도 있으면 expo-screen-orientation 루트 컨트롤러가 잠금 대신 react-native-screens 에 묻는다. 그쪽은 탭 안 홈 화면(옵션 없음)을 "거꾸로 빼고 전부"로 답한다. 옵션을 빼고 루트 잠금 하나로 정했다.

- **나가기는 예전과 같은 "가로 홈 → 회전"이다.** 애니메이션 없이 닫으면 탭 화면이 다시 붙는 0.35초 동안 #1C1C1E 빈 화면이 보였다(dismissTo 든 reset 이든, 확인창이 있든 없든 같다).
  페이드로 닫으면 빈 화면은 없지만, 닫힘이 끝나야 iOS 가 회전을 받아 줘서 가로 홈이 0.5초 보인다. 닫기 전에 드래프트를 `orientation: 'all'` 로 풀고 바로 세로를 요청해 봐도 회전은 닫힘 뒤에 시작됐다.
- **커스텀 진입 0.25초 빈 화면.** 모달이 회전과 함께 뜨는 동안 첫 몇 프레임은 세로 크기로 배치된다. 가로 크기를 기다리지 않고 바로 그리면 세로 배치와 설정 서랍이 0.4초 비치고 자리 잡는 것도 더 늦어서(2.55초 vs 2.1초) 기다리는 쪽을 유지했다. 칼바람은 등장 연출이 이 구간을 덮는다.
- **네이티브 `SafeAreaView` 가 0 으로 굳는다.** 회전과 함께 뜨는 모달 안에서 마운트되면 inset 이 0 으로 잡힌 채 갱신되지 않았다. 아이템 화면 나가기 버튼이 Dynamic Island 쪽에 붙고 타이틀에 덮여 눌리지 않았다. `useSafeAreaInsets` 는 정확했다(좌우 62, 아래 20).
- **`InsetView` 는 평탄화되면 안 된다.** 레이아웃 값만 가진 View 라 Fabric 이 평탄화했고, 칼바람 헤더의 로고·라운드·픽 현황이 접근성 트리에는 있는데 그려지지 않았다. `collapsable={false}` 로 해결.
- 홈 스택 재생성(큰 제목 접힘 우회)은 여전히 필요하다. 끄면 드래프트를 다녀온 뒤 큰 제목이 접힌 채 남았다.
- 녹화 영상에서 저장 순간 16ms 짜리 어두운 프레임이 한 장 잡힌 적이 있다. 연속 스크린샷에서는 보이지 않았다.
