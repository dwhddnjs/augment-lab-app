# 카드 뒤집기 애니메이션이 일부 기기에서만 안 보이는 문제 — 시뮬레이터 검증

- **날짜**: 2026-08-20
- **Verdict**: ✅ **PASS** (원인 확증 + 수정 확인 + 회귀 확인)
- **환경**: iPhone 17 Pro (iOS 26.5), Expo dev client + Metro(:8082), 다크 모드

## 배경

"내 폰에서는 카드가 뒤집히는데 다른 폰에서는 애니메이션 없이 바로 보인다"는 제보.
기기 성능이나 화면 크기로는 애니메이션이 **통째로** 사라지지 않으므로, 기기별로 갈리는
시스템 설정을 의심했다.

## 원인

reanimated 4는 모든 애니메이션의 `reduceMotion` 기본값이 `ReduceMotion.System`이다.
iOS **설정 → 손쉬운 사용 → 동작 → 동작 줄이기**가 켜진 기기에서는
`withTiming`/`withDelay`가 스킵되고 shared value가 최종값으로 즉시 점프한다
(`node_modules/react-native-reanimated/lib/module/animation/util.js:309-318`,
`animation/delay.js:34`). 네이티브는 앱 시작 시 `UIAccessibilityIsReduceMotionEnabled()`를
한 번 읽어 전역 플래그로 캐시한다(`apple/reanimated/apple/REAReducedMotion.h:7`).

즉 **카드가 "바로 보이는" 것이 아니라, flip 애니메이션이 통째로 스킵되고 완료 상태가 첫 프레임에 그려진 것**이다.

## 수정

`aram-card.tsx` / `arena-pick-card.tsx` 두 파일 모두:

- 모든 `withTiming`을 `reduceMotion: ReduceMotion.Never`를 붙인 `timing()` 헬퍼로 통일,
  `withDelay`/`withSequence`에도 `ReduceMotion.Never`를 명시 → 시스템 설정과 무관하게 재생.
- `useReducedMotion()`이 true면 `flipIn = false`로 내려 **회전만** 건너뛰고 기존 fade 경로를 탄다
  (rotateY가 전정기관 자극 요소이므로 접근성 의도는 존중, 등장 자체는 애니메이션으로 유지).

## Steps

시뮬레이터 접근성 설정은 `xcrun simctl spawn <udid> defaults write com.apple.Accessibility ReduceMotionEnabled -bool <v>`
로 토글하고, reanimated가 앱 시작 시 값을 캐시하므로 매번 `terminate` + `launch`로 재시작했다.
애니메이션 중간 프레임을 잡기 위해 `timing()`의 duration에 임시 배율(15~100배)을 걸고 관찰한 뒤 원복했다.

| # | 동작 줄이기 | 코드 | 조작 | 관찰 |
| --- | --- | --- | --- | --- |
| 1 | ON | **원본**(대조군, duration을 16s/38s로 늘림) | 칼바람 → 카드 픽 → 다음 라운드 | 카드 3장이 **완전 불투명·정위치로 즉시** 표시. 38초짜리 회전이 한 프레임도 재생되지 않음 → 제보 증상 재현 |
| 2 | ON | 수정본(100배) | 칼바람 → 카드 픽 → 다음 라운드 | 카드 3장이 **반투명 상태**로 포착 = fade 진행 중. 회전 없음(카드 폭 정상) |
| 3 | OFF | 수정본(100배) | 칼바람 → 카드 픽 → 다음 라운드 | 카드 3장이 **원근 회전으로 눌린 사다리꼴**로 포착 = flip 진행 중 → 기존 동작 회귀 없음 |

Metro 로그도 원인을 뒷받침했다. 동작 줄이기 ON으로 앱을 띄운 세션에서만
`WARN [Reanimated] Reduced motion setting is enabled on this device. ... Some animations will be disabled by default.`
가 찍혔고, OFF로 재시작한 뒤에는 나오지 않았다.

## Findings

- **PASS** — 동작 줄이기 ON 기기에서 카드가 "그냥 나타나던" 문제 해소. 이제 fade로 등장한다.
- **PASS** — 동작 줄이기 OFF 기기의 flip 등장은 종전과 동일(회전 중간 프레임 확인).
- 임시 배율/지연 패치는 모두 걷어냈고, 시뮬레이터의 `ReduceMotionEnabled`도 `0`으로 원복했다.
- `npx tsc --noEmit`, `npm run lint` 모두 통과.

## 남은 것

- `builds/screens/build-list-screen.tsx`의 탭 인디케이터 슬라이드(`withTiming` 2곳)도 같은 이유로
  동작 줄이기 기기에서는 즉시 점프한다. 인디케이터 이동이라 체감이 작아 이번 범위에서는 손대지 않았다.
- 시뮬레이터 검증이므로 실기기(제보자 폰)에서 최종 확인이 필요하다. 확인 요령: 해당 폰의
  설정 → 손쉬운 사용 → 동작 → **동작 줄이기**가 켜져 있는지 보면 원인이 바로 드러난다.
